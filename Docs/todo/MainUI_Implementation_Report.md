## 2026-10-03 보상·결과·전리품 UI 고도화

- 보상 화면을 공통 `FPGUIStyle` 테마로 통일했다. 카드별로 빌드 시작 / 현재 빌드 연계 / 공용 / 핵심 강화 표시를 제공한다. `BuildFamily`, 선행 조건, 장착 효과를 포함한 실제 유효 특성을 사용하며 선택 가능 여부와 지급 권한은 기존 게임플레이 경로를 따른다.
- 보상 카드의 설명은 내부에서 스크롤하고 선택 버튼은 하단에 고정한다. 패널은 화면 크기에 맞추고 카드가 순차적으로 나타난 뒤 입력을 허용한다. 선택 확정 중 중복 입력, 범위를 벗어난 인덱스와 재진입 호출을 차단한다. 저장 실패 시 같은 토큰·카드를 유지하고 실패 안내와 재선택을 제공한다. 빈 보상 풀은 계속 버튼으로 진행한다.
- 결과 화면은 보스 전리품의 아이콘·등급·슬롯·실제 옵션·고유 효과와 강화 목록을 나란히 표시한다. 강화 횟수는 종류 수가 아니라 누적 선택 횟수다. 옵션 표기는 장비 비교 화면과 같은 단위·정렬을 사용한다.
- `FPGRunResultView`는 표시 전용 스냅샷이다. 승리 저장 대기에는 아직 확정되지 않은 보스 전리품과 저장 재시도 버튼을 표시하고, 확정 후에는 별도 결과 슬롯에 저장되었다는 안내와 새 도전 버튼을 표시한다. 새 도전 저장이 실패해도 현재 결과를 보존하고 안내를 갱신한다. 저장 형식과 보상 지급/재개 규칙은 유지한다.
- 월드 전리품은 `UPGUILootOverlay`가 0.1초마다 한 번 갱신한다. 획득 대상 → 등급 → 거리 → GUID 순으로 우선하며 기본 최대 12개 라벨을 재사용한다. 화면의 주요 HUD 영역을 피해 겹치지 않게 배치하고, 밀려난 라벨은 월드 위치와 가는 선으로 연결한다. 표시하지 못한 개수와 근처 전리품 탭 경로를 안내한다. 원거리·화면 밖 드랍은 라벨 검색 범위에서 제외한다.
- E 입력과 라벨 강조는 `APGLootDrop::FindNearestPickup`을 공유한다. 실제 획득 반경 안의 한 대상에만 `[E] 획득`을 붙인다. 드랍별 WidgetComponent는 직렬화 호환을 위해 남겨 두되 위젯 생성·표시를 중지했다. 드랍의 짧은 등장 궤적과 희귀도 빔은 유지한다.
- Project Settings → Game → PG UI Style에서 보상 창 폭, 등장·확정 시간, 카드 간격, 전리품 라벨 수·거리·폭을 조절한다. 이 UI 단계에서 추가한 보상 열기·확정·승리 사운드 슬롯에는 후속 SFX 작업에서 전용 에셋을 연결했다.

## 2026-10-03 장비 UI 고도화 1차

- `UPGUIInventory`를 장착 정보 / 가방 그리드 / 아이템 비교의 세 영역으로 재구성했다. 강화·검술과 근처 전리품은 별도 탭으로 옮겼다. 기존 장착·해제·검술·획득·버리기·저장 복구 기능을 유지한다.
- 가방을 클릭하면 선택만 변경한다. 비교 패널의 별도 버튼으로 장착하며 GUID를 기준으로 선택을 유지한다. 가방 용량은 카탈로그를 따른다. 슬롯 위젯은 재사용하고 아이템 정의·장착 배지가 바뀐 슬롯만 갱신한다.
- 옵션 비교는 두 장비의 옵션 합집합을 사용해 사라지는 옵션도 감소로 표시한다. 치명타 확률은 basis point 원본을 % / %p로 표현한다. 기본 치명타 배율에 더하는 속성은 '치명타 추가 피해'로 표시한다. 두 장비의 조건부 효과 설명을 제공하며 최종 DPS 예측으로 해석하지 않는다.
- 전체 화면 입력 차단 배경, 가변 폭·높이, 영역별 스크롤, 고정 장착/버리기 버튼을 적용했다. 고정 1040×900 뷰포트 크기는 제거했다. Esc는 버리기/복구 확인을 먼저 취소하고 다음 입력에 창을 닫는다. I와 닫기 버튼으로도 닫을 수 있다.
- `UPGUIManager::AcquireModalInput/ReleaseModalInput`을 장비와 스테이지 화면에 적용했다. 이동 차단을 중복 누적하지 않고 기존 외부 차단을 보존한다. 전투 중 장비 창은 일시정지하고 준비/빌드 구간은 멈추지 않는다. 스테이지 화면이 우선하면 장비 창을 정리하며 닫을 때 입력·포커스를 복원한다. 컨트롤러 EndPlay와 위젯 NativeDestruct에서 해제한다.
- `UPGProfileSubsystem::OnProfileChanged`는 저장 확정과 플레이어 반영 이후에만 발생한다. 열린 UI가 구독하고 닫을 때 해제한다. 실패한 작업은 기존 스냅샷·선택을 보존하고 상태 문구를 갱신한다.
- `PGUI/Style`에 `FPGUIStyle`과 `UPGUIStyleSettings`를 추가하고 메인 HUD와 장비 화면에서 공유한다. Project Settings → Game → PG UI Style에서 색상·본문 크기·장비 화면 최대 폭·여백을 조정한다. 브러시는 프로세스 수명 동안 유지하므로 색상 프리셋 변경은 게임 프로세스를 다시 시작해 확인한다.

### 검증과 재현

- UE 5.8 Development Editor 빌드: `Saved/Logs/InventoryUIBuild.log`.

- `Tools/Validation/RunInventoryPresentation.py`는 매 실행 새 `UI_*` 테스트 프로필로 실제 게임을 화면 밖에서 실행하고 캡처·오류·해상도를 검사한다. `PGInventoryProbe`는 비 Shipping의 `-PGTestProfile=UI_*`에서만 작동한다. 입력 검사는 Slate 키 이벤트를 사용하는 자동 검사이며 물리 키보드/마우스 직접 플레이 검증은 아니다.

후속 범위는 결과 화면의 전리품 카드, 강화 카드의 빌드 연관 표시, 월드 전리품 라벨 정리, 패드 탐색, UI 전용 SFX/전환 모션이다. 이번 변경은 장비 화면 중심의 첫 단계다. 프레임 비용 수치는 이번 작업에서 새로 측정하지 않았다.

## 2026-09-21 디자인 개편

- 장식형 금속 프레임을 제거하고 네이비 반투명 패널, 민트 생명력, 라벤더 분노/회피, 둥근 스킬 카드로 구성했다.
- 좌측 상단은 시련·웨이브·목표, 우측 상단은 장비/빌드 버튼이다. 하단 중앙은 얇은 리소스 게이지와 8개 스킬 카드다.

- 체력 25% 이하는 붉은색으로 표시한다. 스킬은 호버/눌림 테두리, 쿨다운 음영과 남은 시간을 표시한다.
- 플레이어 발밑 HP 위젯은 표시·틱·갱신을 제거했다. 기존 BP 호환을 위해 PlayerHpWidget 이름의 컴포넌트는 유지하고 BeginPlay에서 다시 숨김 및 위젯 해제를 적용한다. 적 네임플레이트는 유지한다.

## 연결과 수명

APGPlayerController가 로컬 플레이어에게 UPGUIMainHUD를 생성한다. bUseLegacyHUD를 켜면 기존 HUDWidgetClass를 사용한다.
GAS 생명력/분노, 스킬 핸들러 쿨다운, 스테이지 상태, 기존 인벤토리에 연결한다. 스킬 클릭은 기존 ASC 입력 경로를 사용하고 빈 슬롯·쿨다운·행동 불가 상태에서는 비활성화한다.

0.1초 타이머로 현재 Pawn을 조회하며 제거 시 타이머를 해제한다. 스킬 아이콘은 ID 변경 시에만 로드한다. SafeZone과 축소 전용 ScaleBox를 적용하며 중앙 전투 영역은 히트 테스트를 차단하지 않는다.

## 리소스와 참고

새 프레임은 Slate 벡터 브러시로 그리므로 별도 텍스처 가져오기가 필요 없다. 기존 T_MainHUDPlate와 Tools/Art/MainUI 원본은 더 이상 메인 HUD에서 사용하지 않는다. 스킬 아이콘은 기존 데이터 테이블을 유지한다.
디자인 방향 참고: [원신 공식 PlayStation 소개](https://www.playstation.com/en-us/games/genshin-impact/), [젠레스 존 제로 공식 영상](https://zenless.hoyoverse.com/m/en-us/video?catchSpider=1&id=124310). UI/아트 에셋 복제 없이 정보 위계와 간결한 표현을 프로젝트에 맞게 구성했다.
