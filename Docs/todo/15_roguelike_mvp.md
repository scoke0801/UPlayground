# 액션 파밍 + 로그라이크 빌드 MVP

## 승인된 범위

2026-09-21 사용자 요청: 제안된 MVP를 단계별로 끝까지 구현하고 필요한 리소스를 서브컬쳐 카툰풍으로 제작한다.

- 전사 1명, 직접 조작, 일반 전투 5구간과 보스 1구간.
- 출혈 / 충격파 / 광전사 3축, 전용 강화 12개와 공용 강화 6개.
- 장비·강화는 런 전용, 해금과 기록은 영구 보존. 기존 프로필을 별도 네임스페이스로 보존한다.
- 전설 장비 3개, 무기·장신구 슬롯, 준비 완료 방식 정비.
- 기존 애니메이션과 적 자산을 재사용하고 신규 UI 아트는 선명한 셀 셰이딩, 네이비 배경, 민트·라벤더와 빌드별 포인트 색으로 통일한다.

## 단계와 수용 기준

1. 런 저장·실패·클리어·준비 완료 흐름. 저장 실패와 중복 지급 검증.
2. 실제 피해 경로에 출혈·파동·격분 구현. 재귀 발동 방지, 사망·월드 종료 정리 검증.
3. 18개 강화, 선행 조건·중복 제한·선호 가중치, 전설 장비 데이터와 UI 연결.
4. 6구간 및 역할별 적·최종 보스 데이터 제작, 카툰풍 아이콘 제작·임포트.
5. UE 5.8 빌드·자동 테스트·실제 맵 실행. 실행 근거와 남은 플레이 밸런스 한계를 보고.

## 기존 작업 보존

착수 시 HUD·웨이브·스킬 아이콘 관련 미커밋 변경이 존재한다. 기존 변경을 되돌리지 않으며 새 정책은 데이터로 선택 가능하게 한다.

- 1~4단계 코드·에셋 연결 완료. UE 5.8 빌드, 자동 테스트 12개와 6구간 렌더링 진행 확인.
- 상세 실행 근거와 상용 품질까지의 한계는 [구현 보고서](RoguelikeMVP_Implementation_Report.md)에 기록한다.
