# 인벤토리·장비·능력치 성장 구현 기록

## U10 PCG 시작 맵·추가 부위 콘텐츠 (2026-10-11)

- 게임 기본 맵과 에디터 시작 맵을 `/Game/Maps/L_PG_ProceduralDungeon`으로 변경했다. 패키지 맵 목록은 PCG 던전과 검증용 RogueArena를 포함한다. 기존 U9 세션은 원래 패키지/아레나로 재개하며, 신규 세션은 새 PASS 패키지 보고서의 맵을 따른다.
- 장비 15020~15040: 머리·가슴·손·다리·발·방패·반지 7종에 마법/희귀/영웅 3등급을 추가했다. 등급별 위력은 11~25/26~40/41~55, 드랍 가중치는 1/.5/.15다. 각 부위에 기본 성능과 3개 옵션 풀을 저작했다. 보스 풀은 신규 마법 장비를 제외하고, 던전 보물을 포함한 기존 7개 풀에 연결했다. 드랍 확률·기존 정의 가중치·시작 장비·기존 저장 수치는 보존했다. 부위 증가로 기존 장비의 상대 드랍 비중은 낮아지며 수치는 밸런스 초안이다.
- 전용 투구·흉갑·장갑·다리갑옷·장화·방패·반지·목걸이 아이콘 8장을 built-in ImageGen으로 생성했다. 원본과 프롬프트는 `Tools/Art/InventoryUI/ItemIcons/ExpansionGeneration.json`, 런타임 에셋은 `/Game/UI/Inventory/ItemIcons/T_<부위>`다. 투명 배경을 유지하고 Unreal `ResizeToSpecificResolution`으로 256×256 빌드한다. 기존 검 계열은 검 전용 아이콘으로 통일했다. 캐릭터 3D 방어구 교체나 방패 방어 액션은 이번 콘텐츠 범위에 포함하지 않는다.
- 적용은 `ConfigureEquipmentExpansion.py --apply`, 저장 검사 재현은 `--verify`다. 적용 전 카탈로그 바이트 백업과 SHA-256 대조를 수행했다. 백업: `Saved/InventoryEquipment/Expansion/20261011T104948150678Z`.
- 사전 데이터 검사, 실제 에셋 적용/재로드, 실행기 5검사, 720p/1080p 장착/GAS/표시 검사를 통과했다. 초기 화면 근거: `Saved/QA/20261011T105814Z_eedfb5f2_inventory`. 축소 설정과 최종 검증 근거는 아래 최종 결과에 기록한다.

- 새 Development 패키지의 720p/1080p 장착·GAS·화면 검사 PASS: `Saved/QA/20261011T110714Z_d152be83_inventory`. 양쪽 반지를 포함한 9슬롯 실제 장착과 옵션 합계의 ASC 반영을 확인했다. 패키지 생성 후의 PCG 보물 **검증 도구** 수정은 에디터 검증에 반영했으며, 게임 콘텐츠/장착 기능은 동일하다.

## U9 직접 플레이 수용 환경 (2026-10-11)

- `Tools/PlayInventoryAcceptance.ps1` 및 `Validation/PlayInventoryAcceptance.py`를 추가했다. 기본값은 U8 검증 패키지이며 PASS 보고서의 실행 파일 SHA-256을 대조한다. 새 패키지는 `-PackageReport`로 지정하고 새 세션에서 검사한다. 실행 파일 해시 대조는 패키지 전체 콘텐츠 무결성 검사가 아니다.
- `Saved/InventoryAcceptance/<세션>/User`의 별도 UserDir와 `PGTestProfile=ManualInventory`를 사용한다. 일반 저장을 복사/초기화하지 않는다. `-Session` 재개는 같은 실행 파일 경로·해시를 요구하며 세션의 기록/체크리스트를 덮어쓰지 않는다. 동시에 같은 저장을 열지 않도록 배타 잠금을 사용한다.
- 자동 처치·회복·재료 지급·오프스크린·무음·자동 종료를 사용하지 않는다. 세션 판정은 `AWAITING_MANUAL_REVIEW`이며 게임 정상 종료도 직접 입력 PASS로 바꾸지 않는다. 실행기 강제 종료 후 남은 잠금은 게임 종료를 확인한 뒤 제거해야 한다.
- 체크리스트는 물리 입력/입력 복귀, 실행 중 720p↔1080p 출력 크기 변경, 장착/분배/제작, 정상 종료 재개, 보스/새 런, 30분 플레이와 구간별 경제 기록을 포함한다. 출력 크기 변경과 GPU 동적 내부 렌더 해상도 검사를 구분했다.
- `TestInventoryAcceptance.py` 4개 PASS: 경로 탈출/잘못된 세션 거부, 격리·비보조 실행 인자, 실패 보고서/변경 바이너리 거부, 준비 시 실행 없음·재개 기록 보존·종료 잠금 해제·중복 실행 거부. U8 패키지 해시를 대조하여 `U9_FirstPlay` 세션을 준비했다.
- `U9_FirstPlay` 패키지 실행 후 실제 Development 게임 창과 렌더 기동 로그를 확인했다. 세션은 직접 플레이를 위해 실행 상태로 두었다. 기동 확인은 화면 육안 검수나 물리 입력 수용 결과가 아니다. Python 구문 검사와 추적 파일 공백 검사도 통과했다.
- 게임 제품 코드/에셋은 이번 단계에서 변경하지 않았다. 신규 C++ 빌드/패키징은 수행하지 않았고 U8 기존 패키지를 사용한다. 직접 입력·해상도 전환·실전 경제/전투·장시간 수용은 사용자 플레이 결과를 기다린다. 부위 대표 장비→옵션 풀/드랍 가중치→전용 아이콘은 다음 콘텐츠 작업으로 남는다.

```powershell
./Tools/PlayInventoryAcceptance.ps1 -Session U9_FirstPlay
# 새 독립 세션은 -Session 없이 실행한다.
# 실행하지 않고 체크리스트/패키지 해시만 준비:
./Tools/PlayInventoryAcceptance.ps1 -PrepareOnly
```

기준: `Docs/Design/InventoryEquipment_Design.md`, 2026-10-11. 진행 중이며 전체 구현 완료 보고서가 아니다.

## 구현 전 대조

- `AGENTS.md`, `CLAUDE.md`, 프로젝트 개요의 장비·런·모듈·UI 관련 내용과 기획을 확인했다. 실제 uproject 및 두 Target은 UE 5.8, 모듈은 C++20이다.
- `FPGItemInstance`는 GUID/정의 ID/확정 정수 옵션만 보유했다. 기존 슬롯은 Weapon(0), Accessory(1), 등급은 Common(0), Magic(1), Rare(2)다. 기존 열거자 이름과 값을 유지한다. 새 슬롯 이관은 U2에서 Weapon→주무기, Accessory→목걸이 호환 경로로 진행할 예정이다. 현재 슬롯 변경은 하지 않았다.
- `DA_PGProgression.uasset`이 아이템 배열·드랍 풀·시작 장비를 소유한다. `PGLootRules`는 정의를 선택한 뒤 기본 옵션마다 공통 RollBonus를 추가한다. 부위별 독립 옵션 생성기는 없다.
- `UPGProfileSave` 버전 1은 장비/런 강화/스테이지/RunId/ClaimedLoot/보스 결과를 한 파일에 저장한다. `Commit`은 후보 복제본을 교대 저장한 뒤 플레이어와 UI를 갱신한다. 재료·해금·레벨·경험치·분배는 없다.
- 가방 용량은 장착품을 포함한 Items.Num()이다. 장착은 정의의 슬롯에 GUID를 대입하며 반지 선택·양손 반환 계산이 없다.
- `RestorePlayer`는 확정 Options와 런 강화를 더해 `SetProfileBonuses`에 전달한다. ASC는 이전 효과를 제거하고 새 효과를 적용한다. 무기 액터의 별도 효과 및 전설 중복 정책은 U2/U7A에서 추가 대조해야 한다.
- 방어 공식은 `Attack * DefenseConstant / (Defense + DefenseConstant)`, 치명타는 `BaseCritMultiplier + CritBonusPercent / 100`이다. CriticalRate의 UI 단위는 저장 정수의 0.01%다. 성장 계수는 아직 결정하지 않았다.
- 기존 I 창은 현재 월드에 표시되는 중앙 모달이다. 별도 씬을 이동하는 코드는 확인하지 않았다. 좌우 패널·비모달 입력·경험치 알림·분배 초안은 없다.
- 절차 던전 체크포인트 복원은 프로젝트 개요에서도 미지원이다. U8에서 런 재개 정책과 실제 스폰/드랍 토큰을 함께 검증해야 한다.
- 실제 프로필은 `Saved/SaveGames`, 런 카탈로그는 `/Game/DataCenter/Progression/DA_PGProgression`이다. 사용자의 일반 저장 파일을 시험 대상으로 사용하지 않는다.
- 기존 미커밋 UI/툰/검사 도구 변경을 유지한다. 이번 작업의 UI 수정은 기존 파일 위에 등급 표시 연결만 추가한다.

## U1 변경

- `PGShared/Shared/Structure/PGInventoryTypes.h`: 기존 등급 뒤에 4종 추가. 개체 버전·등급·원본 등급·품질·위력·상위 옵션 표식을 저장한다. 기존 Options는 재추첨하지 않는다.

- `PGProfileSave.h`, `PGProfileSubsystem.{h,cpp}`: 버전 2 이관. 옛 슬롯을 `_BeforeEquipmentV2_<GUID>`로 바이트 백업하고 재로드해 동일성을 확인한다. 성공한 반대 슬롯 저장 후에만 새 상태를 노출한다. 알 수 없는 정의/미래 버전은 읽기 전용이다.
