# 달빛 성소 UI / UX 개선안

## 목표와 진단

전투는 명료하게, 준비는 캐릭터와 빌드에 애착을 느끼게 한다. 기존 화면의 동일한 전폭 버튼, 긴 설명의 연속, 선택/장착 상태 혼동, 화면 중앙의 상시 디버그형 요약을 개선한다.

## 이번 구현

- 아트: ImageGen 내장 도구로 달빛 성소 배경과 실제 캐릭터 캡처를 참고한 초상화 7종 생성. 초상화는 선택용 일러스트이며 3D 외형의 정밀 렌더는 아니다. 원본과 프롬프트를 Tools/Art/MoonlitUI에 보관한다.
- 스타일: 잉크 네이비, 은빛 텍스트, 라벤더 선택 상태, 민트 확인 동작. 얇은 테두리, 절제된 둥근 모서리, 제목/본문/보조 설명의 명확한 크기 차이.
- 장비: 장착 / 가방 / 비교의 기존 역할을 보존하고 새 테마와 헤더를 적용한다.
- 검술: 좌측 아이콘 목록, 중앙 선택 스킬의 상세 설명, 우측 고정 장착 슬롯과 적용 버튼. 강화 내역은 우측에서 별도 스크롤한다. 서로 다른 두 스킬을 함께 저장하며 중복 선택 시 기존 슬롯과 교환한다.
- 캐릭터: 초상화 카드 갤러리와 큰 미리보기, 이름, 현재 사용 상태, 별도 확정 버튼. 미리보기는 저장하지 않는다. 현재 선택도 흐리게 비활성화하지 않고 상태 배지로 구별한다.
- HUD: 큰 빌드 설명 패널을 하단 모서리로 이동, 상태가 없는 텍스트는 숨김. 단축키와 스킬 이미지의 가독성 강화, 다음 시련 시작을 명확한 주요 행동으로 표시.
- 입력: I / Esc 닫기, 기존 모달 일시정지와 게임 입력 차단을 보존. 미적용 스킬 변경은 닫기 전에 적용/취소 안내. 저장 실패·전투 중 변경 불가 이유를 화면에 표시.

## 검증 기준

UE 5.8 Editor 빌드. 격리된 UI_* 프로필로 1280×720, 1920×1080, 2560×1080 캡처 및 저장 실패/빈 가방/입력 복귀 확인. 실제 엔진 캡처에서 잘림, 초상화, 스크롤, 고정 적용 버튼을 검수한다. 자동 검증과 직접 사람의 체감 평가는 구분한다.

## 이후 폴리싱

게임패드 전용 탐색, 정식 캐릭터 설정에 맞춘 일러스트 감수, 보이스와 전용 전환 연출은 별도 후속 범위다. 현재 입력 키를 임의로 안내하지 않고 실제 기존 키를 유지한다.

## 재개 작업 기록

실제 구현·데이터 연결·재현 방법과 검증 근거는 [구현 보고서](SubcultureUI_Implementation_Report.md)에 기록한다. 기본 캐릭터 미리보기, 슬롯 교환과 되돌리기, 미적용 변경의 적용/취소 후 닫기, 저장 실패 재시도 및 준비 완료 후 캡처를 보완했다.
