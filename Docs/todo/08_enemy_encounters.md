# 08. 적 패턴·스킬 선택·텔레그래프

우선순위 P1 / 상태 구현 반영·잔여 검증 있음 / 선행 02, 04, 05 / 규모 중

## 현재 근거

`PGBTService_SelectSkill.cpp`에는 가중치 선택, 거리/체력별 우선순위와 회복·소환 처리가 있다. `CurrentHealth`와 GetStat 반환은 int32이므로 체력 비율 계산이 정수 나눗셈을 수행하며 최대 체력 0도 방어하지 않는다. `CheckNeedHealAlly`는 GetAllActorsOfClass로 적 전체를 찾는다. 쿨다운 중에도 하나를 반환하는 폴백은 실행 태스크의 대기/실패 처리와 함께 검증해야 한다. SkillIndicator와 관련 Notify는 재사용 기반이다.

## 목표와 최소 구현

- 먼저 부동소수 체력 비율·0 방어·블랙보드/타겟 유효성 검사를 적용한다.
- 일반 근접 1종, 원거리 1종, 정예 1종으로 역할을 분리한다. 정예는 예고→공격→회복 구간이 명확한 강한 공격 하나를 가진다.
- 사용 가능 조건과 선택 가중치를 분리한다. 데이터 우선순위가 거리·타겟·소환 한도 같은 필수 제한을 우회하지 않게 한다. 후보 없음은 이동/대기로 전환한다.
- PGAI는 선택/행동, PGData는 가중치·사거리·예고/회복 시간, PGActor는 인디케이터 표현을 담당한다.
- 예고 영역과 실제 판정을 같은 범위 데이터로 생성한다. 시전 취소·사망·스테이지 변경 때 예고를 지운다.
- 적 등록 목록/지역 질의로 반복 전역 탐색을 줄이고 비전투 AI의 갱신 빈도를 낮춘다. 최적화 효과는 11에서 측정한다.

## 수용 기준

- HP 75/100, 25/100, 최대 HP 0에서 올바른 정책/안전한 실패가 나온다.
- 쿨다운/타겟 없음/사망/도달 불가 상태에서 행동이 고착되지 않는다.
- 최대·최소 줌에서 위험 범위와 안전 구역을 식별하며 판정과 예고가 맞는다.
- 정예 패턴을 보고 회피할 수 있고 소환 적이 02의 클리어 정책을 따른다.

디버그: 후보별 제외 이유·가중치·선택 결과·범위 시각화. 후순위: 보스 다중 페이즈와 공격 슬롯 조율. 기존 BT/BP 실제 구성을 에디터에서 먼저 점검한다.

## 2026-09-19 구현 반영

이번 2단계에는 AI 체력 비율의 부동소수 계산과 0 방어, 기존 적/스킬 데이터 참조 검증을 반영했다. 새 정예 패턴·텔레그래프 일치·전역 탐색 최적화는 아직 완료하지 않았다. 기존 몬스터 9종과 스킬 37개를 사용하며 추가 콘텐츠 완성으로 표시하지 않는다.
