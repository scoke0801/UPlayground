# 게임 콘텐츠 기능 구현 계획

작성일: 2026-09-30. 상태: 첫 마일스톤(0~3) 진행 중. 0단계 코드·자동 회귀 검사에 이어 1단계의 적 역할·패턴·웨이브 데이터를 연결하고 자동/렌더링 검증을 보강했다. 직접 조작 수용 검증은 미완료다. 작업 폴더에 있던 2단계 보스 코드 초안은 보존했으며 보스 데이터 이관은 아직 적용하지 않았다. 3단계는 미구현이다. 아래 실행 기록과 각 단계의 완료 기준을 구분한다.

## 목표와 기준선

전사 1명, 기존 RogueArena의 일반 5구간과 보스 1구간을 유지하며, 한 런 안에서 전투 대응법과 빌드 선택이 달라지는 15~20분 플레이를 목표로 한다. 시간은 아직 검증되지 않은 튜닝 목표다. 장비·강화는 런 전용, 기록·선택지 해금은 영구 보존하는 현재 규칙을 따른다.

현재 기반은 기본 공격·액티브 2개·회피, 검술 로드아웃 2개, 출혈/충격파/격분 강화 계열 3개, 강화 18개, 전설 효과 장비 3개, 일반 적 3종·정예 2종·보스 1종이다. 검술 로드아웃과 강화 계열은 서로 다른 개념이다.

출혈 증폭·처치 확산·액티브 폭발, 충격파 반경·메아리·마무리, 격분 지속·회복·피해 감소는 이미 구현되어 있다. 이번 계획은 이를 재구현하지 않고 사용성과 조합의 깊이를 확장한다. 현재 전설 장비는 이름/효과는 전설이지만 데이터 등급은 Rare를 사용한다.

근거: `PROJECT_OVERVIEW.md`, `RoguelikeMVP_Implementation_Report.md`, `16_automated_qa.md`, `ConfigureRoguelikeMVP.py`와 실제 Skill/Stage/Item/Reward/Profile 코드. BP 내부의 실제 행동과 새로운 콘텐츠의 재미는 구현 시 렌더링 플레이에서 확인한다.

## 0. 플레이 가능한 기준선

최근 QA에서 `RogueArena -game -NullRHI` 실행은 적 15101의 스폰 재시도 소진으로 1구간에서 중단됐다. 시간 가속을 제거해도 재현됐다. 아직 NavMesh 문제로 확정하지 않는다.

- 스폰 실패 이유를 에셋 로드, 내비게이션 준비/투영, 경로 연결, 지면 경사, 캡슐 충돌로 구분한다. 실패 위치와 시도 수를 로그/디버그 표시에 남긴다.
- PIE·독립 실행의 월드 및 내비게이션 준비 상태를 비교하고 확인된 원인을 수정한다. 재시도 상한 확대나 강제 스폰으로 실패를 숨기지 않는다.
- 빌드·기존 테스트·에셋 검사·16웨이브/7선택 완주·사망/재시작 20회 통과를 기준선으로 삼는다. 화면이 있는 독립 실행에서도 스폰과 이동을 확인한다.

이후 콘텐츠에 필요한 런 시드, 선택한 보상 ID, 구간별 전투 시간, 직접/추가 피해 및 피격량을 최소한의 로컬 기록으로 추가한다. 체력 보정/자동 처치 실행은 통계에 Assisted로 구분한다. GUID·실행 타이밍까지 포함한 완전 결정론은 목표로 하지 않는다.

## 1. 적 역할과 5구간의 전투 구성

| 적 | 목표 행동 | 플레이어에게 요구하는 대응 |
|---|---|---|
| 추격자 | 근접 접근, 짧은 예고 후 공격, 짧은 추적 중단 | 이동하며 묶어서 처리, 공격 타이밍 읽기 |
| 별빛 사수 | 선호 거리 유지, 조준 방향 확정 후 투사체 발사 | 횡이동·접근·우선 처치 |
| 철갑 수호자 | 전방 방어 상태, 느린 강타 후 방어 해제 | 측후방 접근, 강타 회복 시간에 공격 |
| 정예 분쇄자 | 직선 돌진 후 원형 강타 | 돌진 선에서 이탈한 뒤 착지점 회피 |
| 정예 파수꾼 | 순차적으로 발생하는 지면 위험 구역 | 이동 경로 확보, 공격 욕심 조절 |

기존 BP/BT/몽타주에서 위 행동이 이미 성립하는 부분은 재사용한다. 전방 방어는 정면 피해만 감소시키고 측후방 또는 회복 상태에서 정상 피해를 받도록 판정한다. 수치와 각도는 데이터로 노출한다.

패턴 공통 데이터는 원형·부채꼴·직선 범위, 예고/발동/회복 시간, 조준 추적 종료 시점, 이동 거리/속도와 표현 참조를 다룬다. 하나의 범위 데이터로 예고와 실제 판정을 생성하며, 스킬별 전용 조건문 복제를 피한다. 기존 TelegraphDuration 기반 원형 강타 데이터의 동작은 호환 기본값으로 보존한다.

5구간 구성은 1구간 근접/사수 학습, 2구간 수호자+분쇄자, 3구간 사수 혼합과 위치 선정, 4구간 파수꾼과 위험 구역, 5구간 기존 역할의 종합전으로 잡는다. 각 3웨이브 및 정예 구간은 유지하고, 총 적 수 증가는 실제 성능 측정 이후 결정한다.

완료 기준: 거리 유지/방어 해제/돌진의 행동 차이를 화면에서 식별할 수 있고, 장애물·목표 상실·모든 스킬 쿨다운 상황에서 AI가 고착되지 않는다. 사망·취소·재시작 후 텔레그래프와 지연 판정이 남지 않는다. 동일 공격이 의도한 횟수보다 중복 적중하지 않는다.

## 2. 황혼의 기사 보스전

현재 단일 원형 강타를 다음 세 공격으로 확장한다. 기존 리그/애니메이션을 먼저 재사용하고 독자 모델 제작은 후순위다.

| 공격 | 규칙 | 공략 기회 |
|---|---|---|
| 횡베기 | 부채꼴 예고, 방향 확정, 1회 타격 | 측후방 이동 |
| 돌진 강타 | 직선 예고와 이동, 끝점 원형 공격 | 옆으로 회피 후 긴 회복 시간 공략 |
| 황혼 파동 | 시간차가 있는 원형 위험 구역 배치 | 안전 구역으로 이동하며 공격 기회 탐색 |

1페이즈는 횡베기/돌진 강타로 패턴을 학습시킨다. HP 50% 이하에서 2페이즈로 한 번 전환하고 황혼 파동과 공격 조합을 추가한다. 50%는 초기 튜닝값이며 데이터로 변경 가능하게 한다. 전환은 현재 공격 정리와 동시에 처리하여 이전 타이머가 다음 페이즈에 피해를 주지 않게 한다. 대미지 수신 경로는 GAS를 유지한다.

보스 전용 HP바, 위험/회복 상태 표시, 전환 VFX/SFX, 격파 피드백을 포함한다. 필수 무적 연출은 최소화하고 지속 시간은 데이터로 제한한다.

완료 기준: HP 급감으로 임계치를 넘어도 전환은 한 번, 공격 중 사망 시 추가 피해 없음, 텔레그래프와 실제 공격 범위 일치. 세 빌드 모두에서 공략 가능한지 직접 플레이하고 시간을 기록한다. 자동 처치로 보스 패턴 QA를 대체하지 않는다.

## 3. 세 빌드의 완성 강화와 표현

먼저 기존 18개 강화의 실제 효과·설명·발동 조건을 맞추고, 출혈 중첩/잔여 시간, 충격파 발동, 격분 중첩/유지 시간을 표시한다. 보상 카드에는 선행 조건, 현재 효과에서의 변화, 선택 횟수 제한을 보여준다.

신규 강화는 총 3개로 제한한다. 다음은 구현 후보이며, 기존 몽타주와 피해 이벤트 연결을 확인한 뒤 세부 수치를 결정한다.

| 계열 | 신규 핵심 강화 후보 | 기존 기능과의 연결 |
|---|---|---|
| 출혈 | 출혈 폭발로 처치하면 주력 스킬의 남은 쿨다운 일부 반환 | 중첩 축적 → 폭발 → 다음 대상 전환 |
| 충격파 | 같은 적에게 파동을 누적 적중하면 잠시 방어 약화 | 기존 메아리와 단일 강적 상대 시너지 |
| 격분 | 최대 중첩에서 회피하면 중첩을 소비해 출발점에 잔상 타격 | 공격 지속과 위험 회피 사이 선택 |

핵심 강화는 해당 계열 기본 강화 및 전용 강화 1개 이상을 조건으로 한다. 4·5구간에서 조건을 만족하면 3개 카드 중 1자리를 해당 계열 핵심 강화 후보에 배정한다. 복수 계열 충족 시 계열 후보를 시드 기반으로 선택한다. 이 정책도 데이터로 노출하며 기존 7회 선택 수를 유지한다.

현재 RequiredPerk 단일 조건을 확장할 때 복수 요구 조건을 선택적으로 추가하고 기존 값은 계속 읽는다. 초·중첩·반경을 PerkPercent에 혼합하지 않고 효과별 튜닝 데이터로 둔다. 추가 피해에는 원인 정보를 전달하되 직접 적중 효과의 재귀 발동은 막는다. 다수 대상 적중의 쿨다운 반환/중첩 소비에는 1회 발동 제한을 둔다.

완료 기준: 조건 미충족 후보 제외, 중복 선택 차단, 장비 교체 시 효과 적용/원복, 저장 후 빌드 복원. 세 계열에 대해 고정 보상/적 배치의 비교 시나리오를 두고 직접 조작으로 강화 전후 변화를 확인한다. DPS 동등만을 밸런스 목표로 삼지 않는다.

## 4. 적을 잡고 장비를 고르는 이유

- 현재 전역 DropChance/아이템 가중치에 일반·정예·보스 드랍 풀을 추가한다. 적 데이터의 드랍 풀 ID로 연결하고 기존 값은 기본 풀로 보존한다.
- 정예는 장비 1개를 확정 드랍하고, 보스는 유효 장비 1개와 기록/해금 진행을 보장한다. 확정 드랍은 기존 일반 드랍과 중복 계산하지 않는다. 등급·옵션 범위·계열 가중치는 데이터로 관리한다.
- 기존 6개 장비에 희귀 장비 3개만 추가한다. 출혈 유지/액티브 운용/격분 유지 중 하나에 특화하며 서로 다른 선택 이유를 만든다. 기존 전설 효과 3개는 유지한다.
- 장비 비교에 기본 스탯 변화와 계열 효과를 함께 표시하고 획득 강조·등급별 소리·라벨 겹침을 다듬는다. 핵심 강화 조건에 장착 효과가 기여하는지 UI와 판정을 통일한다.
- 전설 등급을 별도 enum으로 추가한다면 기존 저장 숫자 값을 보존하고 색상·필터·아이콘·드랍 표현을 함께 이관한다. 이름만 전설인 상태와 데이터 등급을 일치시키는 작업으로 취급한다.

보스 보상은 승리 화면 전 또는 결과 화면의 수령 흐름으로 연결한다. 승리 직후 새 런 시작으로 아이템이 초기화되기 전에 획득 이유와 해금 결과를 보여준다. 런 전용 장비를 영구 장비처럼 안내하지 않는다.

완료 기준: 동일 시드의 드랍 정의/옵션 재현, 사망 중복 통지 시 중복 드랍 없음, 가방 포화·저장 실패 시 아이템 소실 없음, 장비 교체 후 GAS 효과 원복. 보스 보상 수령과 승리 기록은 중복 확정되지 않는다.

## 5. 반복 플레이의 선택과 해금

맵 분기 없이 현재 준비 화면에서 2·4구간 진입 전에 일반 도전/위험 도전을 선택한다. 위험 도전은 사수 증원 또는 정예 행동 강화처럼 읽을 수 있는 규칙 하나를 적용하고, 확정 장비 등급 또는 런 재화를 더 준다. 선택한 도전과 추가 보상은 함께 저장하여 재접속으로 결과를 바꾸거나 보상을 반복 획득하지 못하게 한다.

런 재화는 1종만 추가하고 3구간 클리어 정비 중 상점을 1회 제공한다. 판매는 회복·장비·보상 재추첨으로 제한한다. 기본 강화 선택 횟수를 추가하지 않고, 재추첨은 후보 교체만 수행한다. 가격·판매 횟수·회복량은 데이터화하고 구매와 재화 차감을 하나의 저장 트랜잭션으로 처리한다.

결과 화면은 클리어 구간, 전투 시간, 선택 강화, 주요 피해 원인, 사망 원인, 새 해금을 보여준다. 초기 도전 과제는 계열별 보스 격파 3개와 위험 도전 완료 1개로 제한한다. 해금은 시작 장비/검술/도전 규칙 같은 선택지 확장을 우선한다. 영구 공격력 수치 누적은 이번 범위에 넣지 않는다.

신규 런 재화·선택·도전 기록에는 명시적인 저장 이관과 기본값을 둔다. 기존 PGProfile/PGProfile_Rogue/Test 슬롯 구분과 실패 시 원복 정책을 유지한다. 이미 종료된 런에서 해금/승리/구매가 재확정되지 않게 한다.

완료 기준: 상점 중 사망/종료·돈 부족·연속 클릭·저장 실패에서도 재화와 상품이 일치한다. 구간 시작부터 이어하기 시 같은 도전 규칙/보상 후보가 복원되고 이미 받은 보상을 다시 지급하지 않는다. Assisted QA 결과는 정상 도전 해금 근거로 쓰지 않는다.

- 수호자의 파란 전방 부채꼴과 공격의 주황 범위, 회복의 청록 표시를 연결했다. 표현 에셋은 적 초기화 시 준비하고 수명 동안 유지한다. `pg.Combat.EliteDebug 1`은 현재 데이터의 판정 범위를 그린다.
- `TryExecuteSkill`은 일반 AI와 진단이 같은 스킬 보유·쿨다운·페이즈 검사 및 GAS 활성화 경로를 사용하도록 한다. 별도 강제 피해 경로를 만들지 않았다.
