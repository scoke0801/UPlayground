# 소모성 아이템과 체력 회복 기획 초안

작성일: 2026-10-05. 상태: 1단계 회복약·정비 보급 구현 및 에셋 적용 완료. 2단계 전투 중 보급과 전술용 소모품은 후속 제안이다. 모든 수치는 직접 플레이로 조정할 초기값이며, 실제 적용·검증 범위는 [구현 보고서](Consumables_Implementation_Report.md)를 따른다.

현재 난이도 문제를 완화하기 위해 모든 빌드에 **회복약 3회, 최대 체력의 40% 즉시 회복, 재사용 8초**를 제공한다. 일반 5구간과 보스 1구간으로 이어지는 현재 시련에서 각 구간을 체력과 회복약이 가득 찬 상태로 시작하게 한다. 한 구간의 실수를 만회하면서 다음 구간의 패턴을 계속 배울 수 있도록 하는 것이 목적이다.

**현재 구현과 기획 근거**

- `UPGAbilitySystemComponent::RestoreHealth`는 GameplayEffect로 체력을 회복하며 최대치 초과와 사망 상태의 회복을 차단한다. 회복 계산의 기반은 이미 있다.
- 격분 계열 `FrenzyLeech`에는 조건부 흡혈 경로가 있다. 다만 확인한 C++ 입력·아이템·프로필 구조에는 모든 빌드가 사용할 회복 소모품 경로가 없다. 따라서 공통 생존 수단을 제공하고 기존 흡혈은 빌드의 추가 장점으로 유지한다.
- 현재 아이템은 무기·장신구 슬롯, 개별 GUID, 옵션 중심이다. 소모품 수량과 사용 효과를 직접 표현하는 구조가 아니므로 장비 가방에 억지로 회복약을 넣지 않는다.
- 스테이지는 웨이브 전투, 강화 선택, 준비 완료, 다음 구간으로 이어진다. 체력과 회복약 보급은 이 정비 흐름에 연결할 수 있다.
- [기존 콘텐츠 계획](17_content_implementation_plan.md)의 상점·회복 판매는 후속 경제 확장이다. 기본 회복 도입의 선행 조건으로 삼지 않는다.

위 내용은 최초 기획 시 소스와 문서를 대조한 결과다. 이후 1단계 에셋 적용과 실행 검증을 수행했으며, 실제 난이도 측정은 별도다. 사용자가 보고한 회복 부족을 출발점으로 삼되, 회복 부족과 순간 피해 과다는 직접 플레이에서 따로 측정한다.

설계 참고로 Blizzard의 Diablo IV 시즌 11 변경 안내는 제한된 휴대 수량과 최대 체력 비례 즉시 회복을 설명한다. 이 구조를 참고하되, 아래 수치와 구간별 보급은 UPlayground를 위한 제안이다. [Blizzard 공식 회복 시스템 변경 안내](https://news.blizzard.com/en-us/article/24243142/sanctuary-ignites-with-itemization-systems-changes)

**우선 도입할 회복약**

아이템 이름은 달빛 성소의 분위기에 맞춘 **월빛 회복약**을 제안한다. 병을 쓸 때 휴대 수량이 1개 줄고 정비에서 다시 지급되는 소모품이다. 영구 소유 재고나 구매 비용은 첫 버전에 도입하지 않는다.

| 항목 | 초기 제안 |
|---|---|
| 역할 | 피격 후 전투를 이어 갈 기회를 만드는 공통 회복 수단 |
| 회복량 | 사용 시점 최대 체력의 40% 즉시 회복 |
| 휴대 수량 | 최대 3개, 새 도전 시작 시 3개 지급 |
| 재사용 대기시간 | 성공한 사용부터 8초, 게임 내 시간 기준 |
| 기본 입력 | Q, 실제 Enhanced Input 에셋에서 중복 없음 확인 및 연결 완료 |
| 사용 동작 | 이동·공격·대시를 유지하며 즉시 사용, 별도 마시기 몽타주 없음 |
| 피격 상태 | 살아 있다면 피격 경직 중에도 사용 가능, 경직 자체는 유지 |
| 가방 | 장비 가방 용량과 분리한 전용 회복 슬롯 |
| 회복 상한 | 최대 체력, 초과분 소멸 |
| 부가 효과 | 첫 버전은 회복만 제공 |

예를 들어 최대 체력 1,000, 현재 체력 250이면 650으로 회복한다. 현재 체력이 850이면 실제 회복은 150이며 1개를 정상 소모한다. 완전한 체력에서는 소모와 재사용 대기시간 모두 발생하지 않는다.

즉시 회복은 위기에서 입력 결과를 확실히 느끼게 한다. 8초의 간격은 약을 연속으로 먹으며 공격을 맞는 플레이를 제한한다. 최대 체력 비례 회복은 체력 장비가 성장해도 회복약이 계속 유효하게 만든다. 회복량은 치명타·공격력·스킬 쿨다운 감소·격분 발동의 영향을 받지 않는 별도 값으로 둔다.

현재 수치의 회복 총량은 구간당 최대 체력의 120%다. 구간 시작 체력을 포함하면 이론상 220%의 피해를 버틸 여지가 있지만, 초과 회복 손실과 8초 간격 때문에 실제 생존량을 보장하는 값은 아니다.

**보급과 전투 흐름**

첫 버전은 회복약과 정비 보급을 함께 제공한다. 장비 드랍, 강화 선택 횟수, 재화와 독립적으로 지급하므로 어떤 빌드로 시작해도 사용할 수 있다.

| 시점 | 체력과 회복약 처리 |
|---|---|
| 새 도전 시작 | 체력 100%, 회복약 3개, 재사용 대기시간 없음 |
| 일반 구간 안의 웨이브 전환 | 남은 체력·수량·재사용 대기시간 유지 |
| 일반 구간 클리어 후 정비 진입 | 체력 100%, 수량을 3개로 설정, 재사용 대기시간 해제 |
| 강화 선택과 장비 조정 | 보급을 반복 지급하지 않음. 최대 체력이 바뀌면 다음 전투 시작 전에 새 최대치로 정비 회복 확정 |
| 보스 구간 진입 | 직전 정비 결과로 체력 100%, 회복약 3개 보장 |
| 실패 후 새 도전 | 새 도전 시작 규칙 적용, 이전 수량을 누적하지 않음 |
| 체크포인트 재개 | 해당 구간 첫 웨이브부터 체력 100%, 회복약 3개로 재시작 |

각 구간을 독립적인 체력 예산으로 다루는 제안이다. 구간 내부에서는 제한된 회복을 관리하고, 클리어하면 다음 구간을 정상적인 조건에서 배운다. 정비 화면을 반복해서 열거나 강화 보상을 두 번 선택해도 보급량은 늘어나지 않는다.

화면에서는 구간 클리어 시 **“정비 완료 · 체력 회복 · 회복약 보충”**을 짧게 표시한다. 정비 중의 회복약 버튼은 사용하지 않으며, 다음 구간 시작 전에 완전 회복된다는 사실을 보여 준다.

회복약을 넣은 직후에는 기존 적 피해량을 유지하고 체감 변화를 먼저 비교한다. 특히 보스 진입 시 전회복의 영향은 별도로 확인한다. 구간을 넘는 체력 소모가 필요한 상위 난도는 기본 난도 검증 후 보급 정책을 데이터로 분리한다.

**전투 중 보급은 두 번째 단계**

첫 단계 이후에도 긴 구간에서 회복약이 일찍 고갈된다면 **회복약 보급**을 추가한다. 획득하면 월빛 회복약 수량을 1개 보충하며, 체력을 직접 회복하지는 않는다.

| 발생 조건 | 제안 규칙 |
|---|---|
| 일반 구간 | 3웨이브 구성에서 두 번째 웨이브 클리어 시 1개 확정 생성 |
| 보스 | 살아 있는 보스가 체력 50% 이하에 처음 도달하면 1개 확정 생성 |
| 획득 | 도달 가능한 지정 지점에 생성, 200cm 이내 접근 시 자동 획득 |
| 이미 3개 보유 | 획득하지 않고 바닥에 유지, 약을 사용한 뒤 다시 획득 가능 |
| 구간 종료 | 남은 보급 제거, 다음 구간 정비 보급과 중복 누적하지 않음 |

보스 보급은 페이즈 전환 이벤트와 함께 한 번만 발생하며, 회복으로 임계치를 다시 통과하거나 이벤트가 중복 호출되어도 재생성하지 않는다. 치명타로 보스가 바로 사망하면 생성하지 않는다. 정예·일반 적의 무작위 드랍과 소환 적 드랍은 이 단계에 추가하지 않는다.

이 보급까지 활성화하면 한 구간의 회복약 사용 가능 횟수는 최대 4회, 회복 총량은 최대 체력의 160%가 된다. 기본 3회와 분리해서 검증하고, 최초 도입부터 두 보급 정책을 동시에 켜지 않는다.

**후속 소모성 아이템 후보**

월빛 회복약의 사용률과 생존 개선을 확인한 뒤 전술용 슬롯 1개를 추가하는 방향이다. 아래 두 아이템은 후보이며 첫 구현 범위에 포함하지 않는다. 여러 버프를 전투 전에 반복해서 누르는 부담을 막기 위해 전술용 아이템은 한 종류만 장착하게 한다.

| 후보 | 초기 효과 제안 | 용도와 제한 |
|---|---|---|
| 재생 연고 | 최대 체력 30%를 5초간 회복, 최대 2개, 재사용 20초 | 안전거리를 확보한 뒤 추가 회복. 같은 효과 중첩 불가, 피격으로 회복은 끊기지 않음 |
| 수호 향 | 5초간 받는 피해 20% 감소, 최대 2개, 재사용 20초 | 강한 공격을 예상해 미리 사용. 기존 피해 감소와의 결합 및 상한 검증 필요 |

전술용 아이템은 우선 3구간 클리어 정비에서 두 종류 중 하나를 골라 2개 받는 확정 보상으로 시험한다. 회복약의 기본 지급과 기존 강화 선택 횟수를 줄이지 않는다. 이후 기존 계획의 상점이 구현되면 추가 구매를 연결하되, 기본 회복약 확보는 무료로 유지한다.

월빛 회복약을 함께 쓰면 과도한 순간 회복이 생길 수 있으므로, 후속 단계에서는 모든 소모품의 공통 사용 간격을 8초로 두고 전술용 아이템에만 별도 20초 대기시간을 둔다. 장착 교체로 대기시간이 초기화되지 않게 한다. 최종 수치는 첫 회복약 테스트 이후 다시 결정한다.

**조작과 화면 피드백**

- 체력바 가까이에 병 아이콘, `Q`, `3/3`을 고정 표시한다. 기존 액티브 스킬 1~4와 별도 슬롯을 사용한다.
- 대기시간은 아이콘 위 원형 진행과 남은 초로 표시한다. 0개일 때는 `회복약 없음`, 체력이 가득 찼을 때는 `체력이 가득 찼습니다`를 짧게 보여 준다.
- 체력 35% 이하이며 약을 즉시 쓸 수 있을 때만 회복 슬롯을 약하게 강조한다. 최초 도전에서는 `Q 회복약 사용`을 한 번 안내한다. 반복 경고음은 사용하지 않는다.
- 성공 시 짧은 청록색 회복 빛, 한 번의 음향, 실제 회복량 `+400`을 표시한다. 체력바는 실제 GAS 값에 즉시 반응한다. 병 아이콘과 숫자로 색상 이외의 구분도 제공한다.
- 버튼을 길게 누르거나 연타해도 한 번의 누름에서 한 번만 사용한다. 쿨다운 중 입력은 나중에 자동으로 실행하도록 예약하지 않는다.
- 인벤토리·강화 선택·일시정지·결과 창에서는 게임플레이 입력을 차단한다. 회복 입력이 공격 취소·대시 재시작·무적·경직 해제로 이어지지 않도록 한다.

툴팁 예시: **“최대 체력의 40%를 즉시 회복합니다. 8초 후 다시 사용할 수 있습니다. 구간을 클리어하면 3개까지 보충됩니다.”** 실제 키 표시는 Enhanced Input 설정을 따른다.

**현재 코드에 연결할 최소 구조**

아래 구조 중 1단계 회복약 경로를 구현했다. 아이콘은 Slate 벡터 병을 사용하며, 전투 중 보급·지속 회복·피해 감소는 후속 범위다.

| 모듈 | 제안 책임 |
|---|---|
| PGData | `PGConsumableData`에 아이템 ID, 이름, 아이콘, 회복 비율, 수량 상한, 대기시간, VFX/SFX 참조를 저장. 진행 데이터에는 시작·정비·전투 보급 정책 연결 |
| PGActor | `PGConsumableComponent`가 현재 구간의 수량·대기시간·사용 요청을 소유. 플레이어 입력과 StageManager의 정비·구간 수명에 연결 |
| PGAbilitySystem | 사용 시 기존 `RestoreHealth` 경로로 GAS 회복 확정. 이후 지속 회복·피해 감소 효과 추가 |
| PGShared와 PGMessage | 소비 결과·남은 수량·대기시간을 UI에 전달할 가벼운 상태와 변경 알림 |
| PGUI | 회복 슬롯, 툴팁, 불가 사유, 정비 보급 안내 |
| UPlayground/Cheat | 회복약 수량 설정, 체력 감소, 보급 재현 및 사용 기록 도구 |

입력부터 처리까지의 순서는 상태 확인 → 재진입 방지 → GAS 회복 → 실제 회복량이 양수인 경우 1개 차감과 8초 대기시간 확정 → UI 알림이다. 수량은 한 소유자만 변경하며 회복 중 발생하는 콜백이나 중복 입력이 다시 사용 처리를 시작하지 못하게 한다. 체력 0과 사망 태그가 확정된 이후에는 회복이 발생하지 않는다.

현재 프로필 저장의 `Commit`은 동기 저장 후 `RefreshPlayer`를 호출한다. 첫 버전의 회복약은 **구간마다 지급되는 전투 자원**이므로 매번 이 저장 경로를 호출하지 않는다. 수량과 대기시간은 구간 실행 상태로 보관하고, 장비 프로필 변경이나 외형 변경으로 재초기화하지 않는다.

재개 정책은 기존 구간 시작 체크포인트에 맞춘다. 중단 후 재개하면 해당 구간의 적·웨이브와 회복약 사용 상태를 함께 처음부터 다시 시작한다. 보급 이벤트도 해당 구간 재실행에 맞춰 초기화하되 영구 재고로 축적되지 않는다. 현재 장비 전리품의 획득 GUID 중복 방지 정책은 유지한다. 이 정책에서는 중단으로 전투 진행을 되돌리는 것이 허용되며, 진행 중이던 전투와 수량을 정확히 이어 받는 저장은 후속 범위다.

상점 구매·구간 간 재고 이월을 추가할 때는 별도의 저장 수량, 재화 차감과 획득의 원자적 처리, 저장 실패 복구가 필요하다. 현재의 임시 전투 수량을 그대로 영구 인벤토리로 전환하지 않는다.

**작업 순서와 완료 기준**

| 단계 | 제공 범위 | 확인할 결과 |
|---|---|---|
| 1 우선 구현 | 월빛 회복약, Q 입력, HUD, 정비 전회복·3개 보급, 재개 정책, 튜닝 데이터 | 어떤 빌드로도 새 도전 첫 전투에서 회복 가능 |
| 2 필요 시 확장 | 두 번째 웨이브와 보스 50% 보급, 자동 획득 표현 | 긴 전투의 약 고갈 완화와 보급 위치의 가독성 확인 |
| 3 후속 기획 | 전술용 슬롯, 재생 연고·수호 향, 상점 연결 | 기본 회복을 보장하면서 소모품 선택의 차이가 생김 |

1단계 기능 검증은 체력 상한·완전 체력·사망·대기시간·0개·중복 입력, 공격/대시/피격 중 사용, 강화 2회 구간의 중복 보급, 정비 중 최대 체력 변경, 프로필 갱신 중 수량 유지, 실패/재도전/체크포인트 재개를 포함한다. 일시정지에서는 대기시간도 멈춘다. 2단계는 가득 찬 상태의 바닥 보급 유지, 생성 위치 접근 가능성, 보스 임계치 재통과와 치명 피해, 구간 이동 후 정리를 추가 검증한다.

직접 플레이는 출혈·충격파·격분 빌드 각각 같은 런 시드와 장비 조건으로 도입 전후를 비교한다. 자동 처치로 구간을 통과한 결과는 난이도 검증으로 간주하지 않는다. 기존 런 텔레메트리에 회복약 사용 횟수, 실제 회복량, 초과 회복 손실, 사망 시 남은 약과 대기시간을 추가해 다음 기준으로 조정한다.

| 관측 결과 | 조정 방향 |
|---|---|
| 약이 있고 쓸 수 있었는데 사망 | 슬롯 가독성·입력 전달·순간 피해·경직 연계를 먼저 확인 |
| 약을 모두 쓰고 웨이브가 많이 남은 채 반복 사망 | 전투 중 확정 보급을 시험한 뒤 회복량 조정 |
| 남은 약은 있지만 대기시간 중 반복 사망 | 8초에서 6초로 줄이는 실험과 적의 연속 피해를 비교 |
| 초과 회복 손실이 큼 | 툴팁·체력바 피드백·사용 시점 안내 확인 |
| 피하기보다 맞으면서 회복하는 편이 유리 | 적 예고를 유지하면서 회복량·대기시간을 한 항목씩 조정 |

수용 목표는 첫 일반 구간에서 실수 후 회복을 알아보고 사용할 수 있고, 흡혈이 없는 빌드도 보스까지 학습을 이어 갈 수 있으며, 보스의 강한 공격은 여전히 피할 필요가 있는 상태다. 최종 클리어율 목표는 현재 직접 플레이 기준치를 측정한 뒤 정한다.
