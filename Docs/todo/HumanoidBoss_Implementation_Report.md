# 월식의 검성 구현·검증 기록

2026-10-05. 중단된 신규 휴머노이드 보스 작업을 재개했다. `15401` 월식의 검성을 6구간에 연결하고, 기존 `15106` 황혼의 기사 데이터와 일반 15웨이브 편성은 보존한다. [설계 원본](../Design/HumanoidBoss/HumanoidBoss_Design.md)의 다섯 패턴과 두 페이즈가 구현 범위다.

## 전투 동작

| 패턴 | 실행 | 피해 계수·빈틈 |
| --- | --- | --- |
| 초승연참 | 0.85 / 1.75초의 고정 방향 2타. 2페이즈는 2.95초 마무리 추가 | 0.65 / 0.75 / 1.00배. 최종 타격 뒤 1.20 / 1.35초 회복 |
| 월영 찌르기 | 0.80초 예고, 길이 520cm·반폭 55cm 직선 | 1.00배, 1.00초 회복 |
| 월락 돌진 | 1.15초 준비 후 최대 550cm 수평 이동. 실제 끝점에 0.45초 새 예고 | 이동 중 피해 없음. 반경 260cm, 1.40배, 1.65초 회복 |
| 검막 반격 | 공격 두 번 뒤 허용. 0.37초 시작·1초 유지, 정면 120도만 직접 피해 70% 감소 | 성공 후 검막 해제·0.27초 수락·최소 0.65초 반격 예고. 1.10배, 1.25초 회복. 실패는 종료 모션 뒤 1.50초 회복·피해 취약 35% |
| 원월 파동 | 2페이즈 전용, 1.45초 예고. 반경 260~650cm 고리 1회 | 중심 안전. 1.30배, 2.00초 회복 |

- HP 50%에서 1.20초 전환하며 기존 공격·가드·타이머를 취소한다. 2페이즈 우선 순서는 파동 → 돌진 → 연참 → 찌르기이며, 검막은 조건을 만족할 때 선택한다. 사거리·쿨다운을 무시한 강제 콤보가 아니다.
- 패턴 종료 후 0.50초 전투 대기를 보장한다. 중간 연격에는 회복 취약을 열지 않는다. 지연된 타이머는 다음 타격을 즉시 몰아서 실행하지 않고 타격 간격을 보존한다.
- `PGData/Combat/PGEnemyAttackProfile`이 접점·형상·피해·모션 구간과 검막 정책을 소유한다. `PGAbilitySystem`이 타이머·공간 판정·GAS 피해·취소를, `PGAI`가 선택·공격권을 담당한다. 기존 프로필 없는 단발 적의 실행 경로를 유지한다.
- 검막 성공은 GAS 직접 피해 확정 뒤에 한 번만 전달한다. 후방 직접 피해와 지속/추가 피해는 성공을 만들지 않는다. 성공 후 나머지 다단 피해에는 일반 방어를 적용한다.
- 예고·검막·회복·전환·격파를 기존 메시지 경로로 한국어 HUD에 표시한다. 격파 문구는 실제 보스 이름을 사용한다.

## 외형·모션과 원본

- `Tools/Validation/Data/HumanoidBoss.json`이 보스·스킬 수치와 모션 채택/접점 구간의 원본이다. 출력은 `/Game/DataCenter/HumanoidBoss`다.
- P09 남성 강화형의 Armor007 외형·검 그립을 복제하고 표시 크기 1.15배·Sword005를 사용한다. 이동 속도는 345cm/s이며 체력·공격력·드랍은 기존 6구간 기준선을 복제한다.
- AnimeKatana·GrruzamSword·FrankSlash의 원본 15클립을 현재 전투 Skeleton으로 변환한 뒤 기존 P09 표시 리타게팅을 사용한다. 출력에 30FPS 트랙을 굽고 루트 이동·원본 판정 Notify를 제거한다. 원본 클립과 기존 플레이어 변환본은 해시로 보존한다.
- 대기·전진 걷기·전진 달리기를 네이티브 `PGCreatureAnimInstance`와 BlendSpace에 연결한다. 공격 모션은 타격 접점 전후 구간을 타이머에 맞춰 재생한다. 몽타주 Notify가 피해를 중복 생성하지 않는다.
- 연속 모션·양손 그립·FX/SFX 청취의 최종 상용 품질 판정은 아래 자동 검증과 구분한다.

## 재현과 복구

```powershell
# 저장된 데이터와 격리된 실제 GAS 전투·접점 근접 화면 검사
python Tools/Validation/RunHumanoidBoss.py --render --motions --automation

# 원본 수치/모션으로 재생성: 패키지 백업 → 적용 → 새 프로세스 재로드
python Tools/Validation/RunHumanoidBoss.py --apply --render --motions --automation
```

Unreal 5.8에 포함된 Python을 사용한다. 실행별 `Saved/QA/HumanoidBoss_*`에 로그·JSON·PNG와 적용 시 패키지 백업/트랜잭션이 남는다. 적용 이후 검증 실패는 해당 실행의 백업으로 복원한다. 검증 프로필은 일반 플레이 저장과 분리되고 보조 실행으로 표시된다. `PGBossEncounter 15401` / `15106`으로 두 보스의 격리 비교를 시작할 수 있다.

캡처·PIE/콘솔 명령 중 Slate 틱이 다시 호출되던 경로를 재진입 차단으로 보완했다. OS 테두리 PIE 창을 사용해 제목 표시줄이 게임 뷰포트 높이를 차지하지 않게 했고, 근접 카메라는 PIE 월드 수명으로 생성·정리한다. 실행 보고서는 각 검사 시작/완료 때 저장해 중단된 단계도 확인할 수 있다. 자동 테스트만 영어 엔진 문화권을 사용하고 실제 화면은 한국어로 검사한다.

## 확인된 검증과 남은 수용 범위

- 에디터 Development·DebugGame 빌드 통과. 최신 카메라 도구까지 포함한 로그는 `Saved/QA/HumanoidBoss_20261005T134044255239/build-camera.log`, `build-camera-debug.log`다.
- PG 자동 테스트 50개 통과(41개 성공, 9개 기존 경고 포함): `Saved/QA/20261005T133623Z_1765365c/Automation/index.json`. 연참 피해·이탈·중복/지연 콜백·취소와 검막 유지/반격/실패 정리를 포함한다.
- QA 판정 Python 10개·몬스터 편성 Python 4개 통과. 신규 보스 드랍·승리의 누락/중복 커밋 거부 검사를 추가했다.
- 전체 통합 QA `Saved/QA/20261005T133623Z_1765365c/report.json`은 **PASS_WITH_WARNINGS**다. 에셋 검사·16웨이브·강화 선택 7회·6구간 완료·15401의 드랍/승리 커밋 1회·사망/재시작 20회를 확인했다. 별도 완료된 최신 빌드를 사용해 `--skip-build`로 실행했다.
- 최초 전체 QA는 이전 검술 회귀 검사기가 신규 보스의 5개 스킬을 허용하지 않아 실패했다. P0/P1 검사에 선언된 보스 스킬만 허용하도록 수정하고 전체 QA를 다시 실행했다. 최초 실패 보고서 `Saved/QA/20261005T133413Z_36e29971`은 보존한다.
- 저장 재로드·실제 전투 8개와 자율 선택은 `Saved/QA/HumanoidBoss_20261005T133254320111/runtime.json`에서 통과했다. 연참 2/3타, 찌르기·돌진, 검막 성공/실패, 고리 안전/피해, 전환 중 취소·격파·재시작을 검사했다. 정면 직접 피해 배율은 0.30, 후방과 검막 해제 뒤는 1.00이었다.
- 같은 실행의 35개 모션 캡처는 생성됐지만 프로세스 종료 코드가 비정상이어서 실행 전체는 FAIL·트랜잭션은 RESTORED로 보존한다. 검수 카메라를 에디터에 배치하지 않고 PIE 월드에서 생성·정리하도록 변경했다.
- **최종 적용·렌더 검증 PASS**: `Saved/QA/HumanoidBoss_20261005T134502333253/report.json`. 적용·새 프로세스 저장 재로드·실제 전투 8개·모션 35개가 모두 통과했고 각 엔진 프로세스가 종료 코드 0으로 끝났다. 적용 트랜잭션은 **VERIFIED**다. 무관한 테이블 행·일반 구간과 원본 모션/외형 해시 보존을 확인했다.
- 최종 22개 전투 화면과 35개 근접 포즈는 모두 1280×720이다. 근접 포즈에는 7개 공격의 설정된 정확한 접점과 앞뒤 구간을 포함한다. 부채꼴 예고·검막·고리 안전 영역·격파 HUD 및 대표 접점 포즈를 정지 화면으로 검토했다. 캡처 PASS를 양손 접촉·발 접지·연속 모션의 최종 시각 합격으로 해석하지 않는다.

실제 입력으로 첫 피격 뒤 연격 이탈, 돌진 벽/절벽 대응, 30/60/120FPS의 회피 여유와 세 강화 빌드의 처치 시간을 비교하는 작업은 별도 수용 범위다. 현재 자동 실행은 체력 보조와 명령 시전을 사용하므로 난이도·90~150초 처치 시간 달성을 보장하지 않는다. 전용 검광/음향·월식 외형 폴리싱, 양손 접촉과 망토 관통의 연속 검수, 패키지 GPU 성능도 자동 검사 완료와 분리한다.
