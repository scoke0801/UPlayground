# 보유 모션 활용과 스킬 및 몬스터 AI 확장 기획

2026-10-10. 상태: 목록 대조 및 작업 방향 기획 완료, 신규 전투 기능 구현 전.

후속 개선: P0 AI 행동 선택 진단을 추가했다. 적용 범위·사용법·검증 상태는 [AI 개선 기록](MotionExpansion_AI_Implementation_Report.md)을 따른다. 신규 모션 채택과 전투 기능 구현은 별도 단계다.

후속 요청으로 [Dark Knight 보스 제작](DarkKnightBoss_Implementation_Report.md)을 진행하고, [Art 전체 애니메이션 사용 후보 목록](ArtAnimation_UsageCatalog.md)을 추가했다. 아래는 최초 확장 기획이며 보스의 실제 적용 상태는 후속 제작 기록을 따른다.

보유 모션을 **플레이어의 새로운 선택지, 몬스터의 구별되는 행동, 그 행동을 적절히 선택하는 AI**로 연결한다. 첫 제작 묶음은 플레이어 신규 액티브 3종과 몬스터 3종의 추가 행동이다. 등장·경계·회복 동작도 함께 연결해 공격 사이의 정적인 시간을 줄인다. 기존 GAS, 역할 BT, 공격 참여 제한, 스킬 프로필을 확장한다.

## 조사 범위와 현재 기준

- UE 버전은 실제 `UPlayground.uproject`의 EngineAssociation 5.8이다. Unreal C++/GAS 프로젝트 기준이다.
- `CLAUDE.md`, `PROJECT_OVERVIEW.md`, 기존 모션 목록·설계, 현재 역할 AI 코드와 데이터 생성 원본을 대조했다. 작업 중인 기존 변경은 보존했다.
- 보유 목록의 출발점은 [전체 모션 카탈로그](../Design/Animation/Bokusei_Motion_Catalog.md)다. 2026-10-04 당시 Bokusei 변환본 8,646개와 기존 시퀀스 1,585개를 기록한다. 원본 복사본, 방향·루트·자세 변형을 독립적인 새 공격으로 세지 않는다. 이 수치는 이번 전체 재스캔 결과가 아니다.
- 이번 디스크 검사는 기존 스킬·보스 후보 manifest와 신규 생물형 모션을 합친 **207개 고유 패키지**를 확인했으며 누락은 0개다. 원본과 변환본이 함께 포함된 패키지 수다. [CSV 목록](assets/MotionExpansion/inventory.csv), [집계 JSON](assets/MotionExpansion/summary.json), [재생성 도구](../../Tools/Validation/InventoryMotionExpansion.py)를 제공한다.
- 사용 여부는 단계별로 구분한다. `authored_combat_link`는 생성 코드·원본 데이터에서 연결됨, `not_linked_by_creature_combat_config`는 해당 전투 생성기에서 연결하지 않음이다. 후자는 갤러리·레거시·다른 맵까지 포함한 미사용 확정을 뜻하지 않는다. 이전 기획 후보는 별도 보류 상태로 보존했다.
- 이번에는 UE AssetRegistry 참조 그래프, 저장된 BP/DT 재로드, 연속 재생 및 직접 플레이를 새로 실행하지 않았다. 따라서 전 프로젝트 미사용 비율과 최종 채택 가능한 모션 수는 미확정이다.

## 현재 플레이어와 몬스터 구성

플레이어는 기본 100/101/102, 선택 액티브 110~114의 5종, 대시 10000을 기준으로 삼는다. 액티브 추가는 기존 장착·저장 경로를 재사용한다. 슬롯 확장과 기본 콤보 전면 교체는 첫 제작 묶음에서 제외한다. 115는 과거 보고서의 빈 궁극기 항목이며 현재 저장 에셋 확인 전 완성 스킬이나 사용 가능한 신규 ID로 취급하지 않는다.

## 플레이어 신규 스킬 기획

1차는 검술 카탈로그를 **5종에서 8종으로 늘리는 목표**다. 아래 이름·수치는 기획 시작값이며 ID는 DT 전체 충돌 검사 후 배정한다. 슬롯 정책은 유지하고 아이콘·한국어 설명·해금·저장까지 한 스킬의 완료 범위로 묶는다.

| 우선 | 스킬 | 후보 모션 | 기존 스킬과 구별되는 역할 | 초기 행동 목표와 필요한 확장 |
|---|---|---|---|---|
| 1 | 섬광 찌르기 | AS_Player_Sword_DashAttack 또는 Run_Thrust | 긴 질풍연참보다 짧고 좁은 단일 진입 | 250~350cm 전진, 1접점, 총 0.6~0.9초 후보, 쿨다운 4초. 벽에서 중지. 실제 찌르기 궤적이 아니면 명칭·형상을 수정 |
| 2 | 후퇴 절단 | 짧은 light 공격 + Evade_B | 공격하면서 거리를 벌리는 생존 선택 | 먼저 전방 1타 후 180~250cm 후퇴, 쿨다운 6초. 무적 기본 부여 없음. 후방 이동·두 클립 연결·벽 접촉 취소 필요 |
| 3 | 검막 반격 | Revenge_Guard Start/Loop/Accept/Attack/End | 플레이어의 수동 타이밍과 방향 선택 | 최대 0.6초 정면 방어 창, 성공 시 1회 반격, 실패 시 짧은 회복, 쿨다운 8초. GAS 직접 피해 이벤트 판정과 다중 적중 중복 방지 필요 |
| 후속 | 축력 일섬 | heavy_startup/idle + 실제 방출이 확인된 Charge_Attack | 입력 유지 시간과 빈틈을 교환하는 강타 | 입력 유지·해제·중단 상태 추가. 준비 모션만으로 완성 처리하지 않음 |
| 후속 | 연속 검파 | Anime Waves | 여러 번 방향을 선택하는 원거리 기술 | 방출 접점·수량 검수 후 채택. 관통검기의 단순 상위판 방지 |

최초 실험의 총 피해는 기존 동급 액티브를 기준으로 맞춘다. 짧은 스킬은 행동 시간과 안전성의 이점이 있어 긴 집중기와 같은 총 피해를 주지 않는다. 연출상의 타수만큼 proc를 무제한 늘리지 않으며 출혈·충격파·격분의 시전별 상한을 유지한다. 반격이 지속 피해·자기 효과에 발동하지 않도록 발동 자격을 정의한다.

새 스킬은 처음 격리 테스트 카탈로그에 넣고 수용 후 기존 성장 카탈로그에 추가한다. 해금은 기존 구간/클리어 보상 정책을 활용하되 자동 획득과 선택 장착을 구분한다. 특정 신규 스킬 없이는 회피 불가능한 몬스터 패턴을 만들지 않는다.

| 2차 엔트·리치 | 왼팔 베기·왼손 시전, 리치 소환 | 엔트는 측면, 리치는 사거리·자식 상한 조건 | 엔트의 긴 회복, 리치의 소환 중단 기회. 좌우 외형 변주와 신규 기믹을 구별 |
| 2차 검투사·검성 | 짧은 측면 이동·제한된 가드/회피 | 공격 회복이 끝난 뒤, 반응 쿨다운·연속 횟수 제한 | 정예/보스에만 우선 적용. 회피 후 반격 기회 보장 |
| 3차 그리핀·여왕 | 이륙/선회/착륙 또는 도약 | 검증된 착지점·이동 경로·전용 공격권 필요 | 고도와 지면 예고 일치. 비행 전체 내비게이션과 저공 직선 이동을 구별 |

첫 묶음에서는 기존 웨이브 적 수·보상 총량을 유지한 채 일부 타입과 행동을 교체한다. 신규 소환은 기존 자식 수명·중복 드랍 방지·부모 사망 정리를 재사용한다. 15542는 이름이 ‘연속 물기’지만 원본 생성 데이터가 다중 접점 프로필을 지정하지 않는다. 연속 재생과 피해 횟수를 대조해 실제 타수와 명칭을 맞추는 작업도 포함한다.

## AI 개선 방향

### 이미 있는 기반과 실제 부족한 부분

`PGRoleAIController`는 거리·시야·쿨다운·페이즈·소환 상한으로 후보를 거르고, 복수 후보에서는 직전 스킬을 제외한 가중 선택을 한다. 대기 중 선택은 유지한다. 보스 반격 후보는 다른 후보보다 먼저 선택하며 2페이즈는 지정 순서를 우선한다. `PGCombatDirectorSubsystem`의 공격 비용·FIFO 예약과 BT의 Ability 종료 대기를 보존한다.

현재 위치 선정은 주변 8개 후보·최대 2개 경로 요청으로 제한된다. 다만 신규 생물형 생성기는 Positioning을 모두 끈다. 후퇴는 지상 Shooter에 한정되며 Flying은 바닥 탐사와 타겟 방향 이동을 사용한다. 따라서 새 모션을 넣어도 그리핀의 선회나 식물의 각성이 저절로 생기지 않는다.

### 단계별 변경

| 우선 | 개선 | 구현 방향 | 완료 기준 |
|---|---|---|---|
| P0 | 관측 가능한 행동 선택 | 후보 탈락 이유, 선택 이유, 공격권 대기, 이동 실패, 모션/SkillID 기록 | ‘스킬이 있는데 왜 안 쓰는가’를 거리·쿨다운·시야·예산으로 구분 |
| P1 | 상황별 선택 가중치 | 기존 필터 뒤 거리 구간·상대 방향·최근 사용 이력·역할 가중치 적용 | 근거리 전용/원거리 전용 행동이 자기 조건에서 선택되고 반복 독점 없음 |
| P1 | 선택 안정성 | 선택 유지 시간을 두고 타겟 상실·범위 무효·긴 대기에서만 재평가 | 공격권 FIFO를 재추첨으로 잃지 않고 좌우 흔들림 없음 |
| P1 | 준비·공격·회복의 행동 잠금 | GAS가 공격 상태와 취소를 소유, BT는 종료 후 이동/가드 선택 | 회복 중 자동 가드·회피가 반격 기회를 지우지 않음 |
| P1 | 역할별 제한된 재배치 | 기존 Positioning을 지상형부터 개별 활성화, 이동 쿨다운·최소 개선 유지 | 이동형 식물/검투사 밀집 해소, 고정형에는 MoveTo 0회 |
| P2 | 반응형 가드·회피 | 관측된 공격 준비/직접 피격 이벤트, 반응 지연·횟수·쿨다운 데이터 | 일반 무리 전체가 동시 회피하지 않고 입력/미래 명중을 읽지 않음 |
| P2 | 보스 선택 균형 | 기존 반격의 최우선 정책에 역할별 제한, 연계 후 명시적 빈틈 | 가드가 준비될 때마다 다른 패턴을 독점 차단하지 않음 |
| P2 | 공중형 선회와 복구 | 저공 전용 후보 지점·장애물/바닥/높이 확인, 실패 시 안전 정지·재선정 | 벽·낭떠러지 접근·바닥 미검출에서 관통과 영구 추적 정체 방지 |

첫 선택 점수는 `기본 가중치 × 거리 적합도 × 방향 적합도 × 최근 사용 감쇠` 정도로 제한한다. 조건이 없는 기존 데이터는 기존 동작을 유지한다. 실제로 사용할 몬스터부터 데이터를 추가하며 범용 AI 프레임워크나 BT 전면 재작성은 하지 않는다.

공격권은 강한 행동이 화면을 동시에 덮는 것을 막는 장치다. 행동을 늘리면서 전역 압박 상한부터 올리지 않는다. 소환체를 포함한 전체 압박, 화면 밖 공격, 긴 도약의 예약 유지·취소를 함께 검수한다. 관측용 난수는 런 시드와 개체 식별에서 분리해 재현 가능하게 만드는 것을 후속 개선으로 둔다. 현재 선택은 `FMath::FRand()`다.

## 모듈과 데이터 책임

- **PGData**: 스킬·적·모션 매핑, 선택 가중치와 반응 제한, 등장/회복 표현 프로필. 피해·이동·예고 수치는 데이터로 노출한다.
- **PGAI**: 후보 판단, 제한된 위치 조절, BT 실행·공격권. 피해 판정이나 애니메이션 접촉 시간을 중복 소유하지 않는다.
- **PGAbilitySystem**: Commit, 효과·피해·반격 자격·취소, 기존 적 패턴 실행과 정리.
- **PGActor**: 플레이어 논리 시계·공간 판정, 캡슐 이동, 모션/표현 및 생명주기. 기존 런타임 책임 분담을 따른다.
- **PGUI**: 신규 스킬 장착·한국어 설명·쿨다운·잠금 사유. **UPlayground/Cheat 및 Tools/Validation**: 관측·격리 시나리오·검수 도구.

플레이어의 후퇴 이동·수동 반격, 생물형 등장, 공중 재배치는 별도 코드 확장이 필요한 항목이다. 기존 프로필의 모션 필드 교체만으로 완료 처리하지 않는다.

## 실행 순서와 완료 판정

| 단계 | 산출물 | 통과 후 다음 단계 |
|---|---|---|
| P0 실제 사용 대조 | 현재 DT/DA/ABP/몽타주와 맵·웨이브 도달 경로, 후보 207개 사용 상태 갱신 | 문자열 경로·동적 로드까지 확인. 삭제 목적의 미사용 판정과 구분 |
| P0 후보 연속 검수 | 첫 묶음 모션의 원본·대상 Skeleton, 접점·타수·루트 이동·그립 기록 | 원본→대상 리타게팅→몽타주→전투 프로필 경로 확정 |
| P1 첫 수직 구현 | 섬광 찌르기 + 그리핀 Attack_2 + 상황 선택 관측 | 한 스킬·한 몬스터의 모션·판정·AI·취소·UI 검증 완료 |
| P1 첫 묶음 완성 | 후퇴 절단·검막 반격, 식물 각성·여왕 추가 공격 | 플레이어 액티브 후보 8종, 몬스터 3종 추가 행동의 직접 전투 수용 |
| P2 다양화 | 등장·피격/회복·좌우 행동, 제한된 반응 AI·소환 | 혼합 웨이브와 보스전에서 공정성·처치 시간·밀집 가독성 수용 |
| P3 확장 | 공중 전이·도약·창/대검/술사 등 무기 역할 | 착지·그립·성능 비용을 개별 통과한 항목만 투입 |

각 단계는 다음 기준으로 판정한다.

1. **모션과 피해 일치**: 공격 예고·접점·판정·회복을 연속 재생에서 대조한다. 의도된 무피해 장식과 실제 타격을 구분한다. 루트 이동과 캡슐 전진을 이중 적용하지 않는다.
2. **플레이어 조작**: 입력 버퍼·회피 취소·벽 막힘·사망·장착 변경·저장 복원, 발사된 투사체 수명과 시전별 proc 상한을 검증한다.
3. **AI 사용성**: 조건을 갖춘 통제 시나리오에서 신규 스킬이 자율 선택된다. 조건이 안 맞으면 선택되지 않는다. 후보가 있는데 장시간 대기하면 탈락 이유가 남는다.
4. **정리**: 등장/소환/비행/반격 도중 사망·트리 중단·스테이지 종료 시 피해·이동·예약·자식·타이머가 남지 않는다. 소환 상한과 진행·드랍 중복 방지가 유지된다.
5. **공정성**: 방향 확정 후 피할 공간과 시간이 있고, 회복 중 공격 기회를 보장한다. 출혈·충격파·격분 각각으로 같은 전투 조건을 비교한다. 자동 처치 완료를 재미·난이도 수용으로 대신하지 않는다.
6. **성능**: 동일 시드·해상도·하드웨어에서 5/20/50마리 전후 비교. 프레임·GameThread p95와 AI 판단/경로 요청 수를 기록한다. 20분 패키지 전투 60fps 목표(프레임 16.7ms)를 별도 수용하며 미달 시 표시·VFX·AI 비용을 구분한다.

적용 도구는 원본을 보존하고 프로젝트 전용 파생 에셋을 생성한다. 테이블·에셋 백업과 변경 manifest, 새 프로세스 저장 재로드 검사를 사용한다. 기존 `RunQA`, `RunHackSlashP0/P1`, `RunCreatureCombat`, `RunCombatBT` 및 보스 검증 도구 중 해당 변경의 검사를 확장한다. 실패 종료 코드는 캡처 성공과 분리해 기록한다.

## 기존 기획과의 관계

[기존 플레이어 기획](../Design/MotionBasedSkills/PlayerSkills_Design.md), [몬스터 기획](../Design/MotionBasedSkills/MonsterSkills_Design.md), [검성 설계](../Design/HumanoidBoss/HumanoidBoss_Design.md)는 모션 후보와 초기 의도를 참고한다. 이후 구현된 검성 반격·신규 생물형·방향 이동을 재개발 목록에 중복 포함하지 않는다. 이전 문서의 액티브 슬롯 설명과 수치 표는 실제 저장 데이터 및 최신 적용 스크립트와 다시 대조한다. 특히 기초 HackSlash JSON만으로 후속 다단 접점·VFX 적용 상태까지 판단하지 않는다.

이번 변경은 이 기획, 정적 목록 생성기와 목록 결과에 한정한다. C++·게임 에셋·전투 수치는 수정하지 않았으며 신규 기능 빌드/플레이 테스트 결과를 주장하지 않는다.
