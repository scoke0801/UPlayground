# 몬스터 배리에이션 확장

## 구성

기존 몬스터 리소스를 이용해 시련 편성에 5종을 추가하고, P09 남녀를 각각 일반·강화·정예로 구성한다. 외형·공격·능력치·드랍·웨이브를 함께 연결한다. 원본 아트와 레거시 몬스터 ID는 보존한다.

| ID | 몬스터 | 역할 | 체력 / 공격 / 방어 | 첫 등장 |
|---|---|---|---|---|
| 15201–15202 | 용병 남녀 | 검격 추격 | 1300 / 85 / 35 | 1구간 |
| 15203–15204 | 숙련 검투사 남녀 | 검격·찌르기 | 2100 / 125 / 70 | 3구간 |
| 15205–15206 | 정예 철갑기사 남녀 | 정면 방어·강타 | 4300 / 185 / 120 | 4구간 |
| 15301 | 새끼 거미 | 빠른 근접 추격 | 800 / 65 / 15 | 1구간 |
| 15302 | 거미 여왕 | 전방 휩쓸기·연속 거미줄 지대 | 6500 / 205 / 65 | 4구간 |
| 15303 | 망령 리치 | 망령탄·저주 지대 | 1900 / 130 / 30 | 3구간 |
| 15304 | 고목 엔트 | 느린 휩쓸기·뿌리 강타 | 3200 / 165 / 100 | 2구간 |
| 15305 | 돌격 골렘 | 돌진 분쇄·지면 강타 | 5800 / 210 / 130 | 2구간 |

- P09 장비: 일반 Armor003 + Sword001, 강화 Armor007 + Sword003, 정예 Armor012 + Sword005 + Shield005. 정예는 정면 피해 감소 55%, 엔트는 35%이며 공격 후 회복 중에는 방어가 풀린다.
- 등급 능력치는 `DT_CharacterStat`, 패턴과 예고·회복 시간은 `DT_Skill`, 역할·드랍은 `DT_Enemy`가 소유한다. 무기 메시 자체가 추가 피해를 중복 적용하지 않는다.
- 정예 철갑기사는 기존 분쇄자 드랍 풀을 사용해 보상을 보장한다. 나머지는 해당 전투 역할의 기존 드랍 풀을 재사용한다.
- 1~5구간 15웨이브의 기존 총수와 보상·타이밍 필드를 유지한다. 6구간 황혼의 기사 보스 편성도 유지한다. 소환·알 부화는 이번 공격 구성에 포함하지 않는다.

## 구현과 재현

- 원본: `Tools/Validation/Data/MonsterVariations.json`. 수치·스킬·갑옷·무기·편성을 한곳에서 편집한다.
- 출력: `/Game/DataCenter/MonsterVariations`와 기존 적·능력치·스킬·사망·스테이지 테이블.
- `PGCharacterAppearance.Attachments`는 고정 장비를 표시 메시 본에 부착한다. 충돌·내비게이션 영향은 없고 외형 교체·EndPlay 시 컴포넌트를 정리한다. P09의 100배 손 본 스케일은 부착 변환에서 보정한다.
- 골렘은 `PGCreatureAnimInstance`의 속도 블렌드스페이스와 몽타주 슬롯을 사용한다. 캐릭터의 `CreatureLocomotion`에 `BS_Golem`을 지정하고 메시의 AnimClass에는 네이티브 클래스를 직접 연결한다. 빈 AnimBP가 네이티브 그래프를 덮는 문제를 피하며, 기존 Fantasy Pack의 대기·걷기·달리기·공격·피격·사망 모션을 재사용한다.
- 공격은 별도 시퀀스·몽타주로 복제해 기존 충돌/투사체/소환 노티파이를 제거하고 `PGEnemyAbilityAttack`의 패턴 판정에 연결한다. 원본 리소스는 수정하지 않는다.
- `RunMonsterVariations.py --apply --render`: 패키지 백업 → 적용 → 새 프로세스 재로드 → 실제 11종 GAS/렌더 검증. 실패 시 엔진 종료 후 원본 복구. 실행별 로그·트랜잭션·캡처는 `Saved/QA/MonsterVariations_*`에 남긴다.
- `TestMonsterVariations.py`: 웨이브 총수·멱등성·혼합 스폰 타이밍 거부·등급 증가와 해금 순서 검사.
- 기존 콘텐츠 재생성 및 P09 웨이브 도구가 새 편성을 보존하도록 연결했다. `ValidateContentMilestone.py`도 신규 에셋 검사를 포함한다.

## 검증 기록

- Unreal Engine 5.8.2 에디터 빌드 통과.
- 편성·등급 Python 검사 4개, QA 판정 회귀 검사 9개 통과.
- 에셋 적용과 별도 프로세스 저장 재로드 통과. 무관한 테이블 행·스테이지 필드 보존과 공격/사망 스켈레톤 호환성을 검사한다.
- 최종 렌더 검사: `Saved/QA/MonsterVariations_20261005T113622267005/report.json` PASS. 11종의 GAS 체력·공격력, P09 6종의 장비 개수·스케일·충돌 비활성화·외형 교체 정리, 19개 몬스터/스킬 조합의 활성화·몽타주·실제 피해·회복 종료를 검사했다. 실행별 PNG로 장비와 몬스터 외형을 검토했다.
- 골렘은 몽타주 시계뿐 아니라 손·머리 본의 포즈 변화를 측정했다. 두 공격에서 약 145cm / 133cm 이동해 정지 포즈 회귀를 감지한다. 마지막 적용 트랜잭션은 `Saved/QA/MonsterVariations_20261005T113404270313/transaction.json` VERIFIED다.
- 통합 실행 `Saved/QA/20261005T113606Z_439cd812`: 자동 테스트 48개, 에셋 검사, 16웨이브·보상 7회·보스 클리어, 사망/재시작 20회가 완료됐다. 엔진 프로세스 모두 정상 종료했다. 드랍 로그의 `result`를 성공 여부로 잘못 읽던 검사기를 수정한 후 동일 원본 로그를 재검사했고 `recheck.json`은 PASS_WITH_WARNINGS다. `result=0`은 바닥 드랍, `1`은 보스 결과 보상이다. 최초 실패 보고서는 덮어쓰지 않았으며 재판정 파일에는 입력 로그와 검사기 해시를 남겼다.
- 기존 테스트용 월드의 무기·월드 컨텍스트 경고, GameplayCue 검색 경고 및 기존 EnemyNamePlate 직렬화 경고는 남아 있다. 이번 검사는 패키징·GPU 성능 검사를 포함하지 않는다.
- 위 검사는 보조 명령·Python을 이용한 검증이며 직접 입력 플레이 판정은 아니다.

직접 조작에 의한 난이도 평가와 밀집 전투 성능은 자동 검사와 별도로 평가해야 한다.
