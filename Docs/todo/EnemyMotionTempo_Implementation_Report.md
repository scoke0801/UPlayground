# 몬스터 공격 동작의 리듬 개선

2026-10-11. 위치 높이나 접지가 아니라 동작의 흐름과 무게감에 대한 피드백을 대상으로 한다.

## 데이터 점검과 적용 범위

`InspectEnemyMotionTempo.py`로 저장된 DT_Skill과 실제 몽타주 길이·원본 구간을 읽었다. 동기화된 적 공격 40개 중 P09 창병·대검병 6개는 적중 전 전체를 긴 예고 시간에 맞춰 원본의 0.14~0.35배로 재생하고 있었다. 같은 무기를 사용하는 일반/숙련/정예 남녀 12종(15701~15712)에 적용한다. 술사와 보스·비인간형은 이번 속도 조정을 일괄 적용하지 않는다.

| 스킬 | 원본 길이 | 기존 적중 전 배속 | 새 휘두르기 시간 | 새 휘두르기 배속 |
|---|---:|---:|---:|---:|
| 15751 회전 창격 | 0.833초 | 0.208 | 0.12초 | 0.972 |
| 15752 내려 베기 | 1.000초 | 0.353 | 0.17초 | 0.971 |
| 15753 축력 창격 | 0.833초 | 0.139 | 0.14초 | 0.833 |
| 15754 대검 횡베기 | 1.400초 | 0.245 | 0.16초 | 1.006 |
| 15755 올려베기 | 1.000초 | 0.205 | 0.15초 | 0.967 |
| 15756 내려찍기 | 1.333초 | 0.296 | 0.20초 | 1.000 |

모션 원본의 품질이나 모든 몬스터의 어색함을 확정 진단한 결과는 아니다. 현재 데이터로 확인되는 과도한 시간 늘이기를 우선 개선한다.

## 구현

- `FPGEnemyMotionTempo`는 준비 종료 포즈, 휘두르기 시간, 후속 동작 종료 포즈와 시간을 소유한다. 선택한 단일 Sweep/Thrust 공격만 명시적으로 활성화한다. 값과 구간 순서, 지원하지 않는 복합 공격 설정을 실행 전에 거부한다.
- 준비 → 휘두르기 → 후속 동작 → 자세 복귀의 네 구간을 정상 몽타주 재생으로 연결한다. 매 프레임 포즈를 50Hz 타이머로 지정하지 않고 구간 경계에서만 재생 위치·배속을 조절한다. 지연된 경계 콜백은 절대 시각으로 현재 포즈를 계산한다.
- 기존 판정 타이머·적중 포즈·공격 전체 길이·취약 시간·사거리·피해·쿨다운은 유지한다. 새 시각 타이머는 피해를 발생시키지 않으며 취소·사망에서 정리한다.
- `AimTurnRate`는 준비 중 회전을 초당 각도로 제한한다. 활성화 순간 타깃으로 즉시 돌리지 않으며, 기존 추적 종료 시간과 휘두르기 시작 중 빠른 쪽에서 조준을 고정한다. 예고 방향과 실제 판정 방향은 같은 `PatternForward`를 사용한다. 기본 0은 기존 동작을 유지한다.
- 저작 원본은 `Tools/Validation/Data/P09WeaponVariations.json`이다. 전체 P09 생성기도 같은 값을 적용하며, 전용 적용기는 DT_Skill의 6개 행에서 새 두 필드만 바꾼다. 원본 모션·몽타주·외형을 재생성하지 않는다.

## 재현·검증

UE 5.8에 포함된 Python으로 실행한다.

1. `Tools/Validation/RunEnemyMotionTempo.py --step inspect`: 저장된 적 모션 조사.
2. 에디터 Development 빌드 후 `--step apply`: DT_Skill 백업, 제한된 변경, 새 프로세스 재로드와 나머지 행/필드 동일성 검사. 실패 시 해당 트랜잭션을 복구한다.
3. `RunP09WeaponVariations.py --step runtime --render --tempo`: 실제 시전의 네 배속·피해 시점·손 본·무기 부착·회복 종료와 중간 렌더 기록. `--enemy 15711`로 개별 대검병을 지정한다.
4. `PG.Content.EnemyMotionTempo`와 확장한 `PG.Content.PatternLifecycle`은 잘못된 데이터, 조준 각속도·고정 시점, 취소와 사망 후 시각 타이머 정리를 검사한다.

| 검사 | 결과 | 근거 |
|---|---|---|
| 개선 전 대검병 3시전·72개 중간 렌더 | PASS | `Saved/QA/P09Weapons_20261011T074350206522` |
| Development 에디터 빌드·최종 소스 최신 상태 | PASS | `Saved/EnemyMotionTempo/build.log`, `build-final.log` |
| 6개 스킬 저장·새 프로세스 재로드·나머지 필드/행 동일성 | PASS | `Saved/QA/EnemyMotionTempo_20261011T075254454066` |
| PG 자동 검사 72개·공통 에셋 검사 | PASS_WITH_WARNINGS | `Saved/QA/20261011T075422Z_4422e90d` |
| 18종 외형·36개 실제 시전·9개 자율 스킬 선택 | PASS, 프로세스 종료 코드 0 | `Saved/QA/P09Weapons_20261011T075436058749` |

공통 QA는 앞서 빌드한 바이너리를 사용했다. 자동 검사 61개는 경고 없이, 11개는 경고와 함께 통과했으며 실패는 없다. 경고는 테스트 월드의 시작 무기·소멸 문맥, GameplayCue 설정 등을 포함한다.

변경 공격은 남녀·등급별 24회 시전에서 네 배속이 실제 적용됨을 확인했다. 최초 피해 관측은 각 예고 종료 후 0~46ms 이내였으며 앞당겨진 피해는 없었다. 총 945개 렌더 중 중간 포즈는 837개다. 캡처 부하로 일부 구간 표본을 건너뛰므로 고정 프레임률 영상·성능 측정으로 취급하지 않는다. 창병 축력의 준비/적중/후속 동작 및 대검 횡베기의 개선 전후 대표 렌더를 직접 확인했다. 전 프레임의 미술 수용을 뜻하지 않는다.

기계 판독 가능한 배속·시점·검증 개수 요약: [evidence.json](assets/EnemyMotionTempo/evidence.json). 데이터 복구가 필요하면 적용 폴더의 `transaction.json`과 `backup`을 기존 `PlayableCharacterTransaction.restore`로 복원한다.

## 남은 품질 범위

직접 조작에 의한 연속 모션·회피 난이도·청취 수용과 패키지 장시간 성능은 자동 검사로 대체하지 않는다. 다른 몬스터의 원본 자세·리타기팅, 이동 중 방향 전환, 다단 보스 프로필의 포즈 갱신은 별도 사례를 확인한 뒤 조정해야 한다.
