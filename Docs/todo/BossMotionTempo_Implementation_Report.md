# 보스 모션 리듬 개선 — 2026-10-11

## 변경

- 프로필 공격은 정지된 몽타주 포즈를 50Hz로 바꾸던 방식에서 프레임마다 진행하는 재생으로 변경했다. 기존 프로필 시계에 맞춰 위치·배속을 보정하며, 같은 몽타주의 연속 타격에서는 재시작/블렌드 인을 반복하지 않는다. 피해는 기존 타이머만 발생시킨다.
- 흑철 15613: 두 번째 모션 시작을 1.35초에서 1.73초로 옮겼다. 1타 후 연결은 3.72→1.47배, 다음 준비는 0.98→1.46배가 된다. 적중은 1.10/2.50초, 최종 회복은 1.80초로 보존한다.
- 검성 15402: `SwingStartFraction=.06`, `SwingSeconds=.20`으로 0.60초 준비와 0.20초 찌르기를 나눴다. 찌르기는 0.25→0.80배, 준비는 0.067배다. 0.80초 예고·적중과 1.00초 회복은 보존한다.
- 검성 15401: 1페이즈 마지막 모션 끝을 .42→1.0으로 확장해 회복 동작을 끝까지 재생한다(0.16→0.72배). 2페이즈는 세 번째 공격으로 이어지므로 기존 .42를 유지한다.
- 새 구간 필드는 기본 0으로 기존 데이터를 유지하며, 활성화 시 최소 준비/휘두르기 시간과 포즈 순서를 검사한다. 기존 종료 처리에서 몽타주·판정 타이머를 함께 정리한다.
- 반응형 AI는 공격/회복 중에도 시전을 관측한다. 기존에는 잠금 해제 후에야 시전을 처음 관측하고 반응 지연을 새로 시작해, 다음 공격을 먼저 선택하면서 가드 기회를 반복해서 놓쳤다. 행동 잠금·회전 잠금·반응 지연·가드 쿨다운은 유지한다. 비반응형 적은 잠금 중 추가 시야 검사를 하지 않는다.
- 검성 저장 데이터의 `bPrioritizeGuard=false`도 가드를 2페이즈 공격 순서 뒤로 밀고 있었다. 이를 true로 바꾸고 `ConfigureMotionExpansion.py` 생성/검사에도 반영했다. 반응 조건·공격 횟수 조건·0.25초 지연·14초 반복 제한을 통과한 가드만 우선한다.

## 저장 및 재현

`RunBossMotionTempo.py --step apply`는 세 프로필과 DT_Enemy를 백업/저장하고 새 에디터 프로세스에서 재로드한다. 나머지 타격 필드·2페이즈 배열·검성의 가드 우선순위 외 모든 적 필드가 동일한지 비교한다. 실패하면 에디터 종료 후 원본을 복구한다. 정식 보스 생성기의 JSON과 적용/검사 경로도 같은 값을 사용한다.

검증 명령:

```text
RunDarkKnightBoss.py --step runtime --stage-roster
RunHumanoidBoss.py --render --automation --encounter-only
```

## 범위와 한계

현재 스테이지의 흑철과 보존된 검성을 개선한다. 구형 황혼의 기사 15106은 공용 단일 슬램을 사용하는 별도 경로이며 이번에 클립을 새로 제작하거나 교체하지 않는다. 직접 조작/청취 및 패키지 검수는 별도다.
