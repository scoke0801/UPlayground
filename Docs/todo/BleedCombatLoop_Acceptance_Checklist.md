# 전사 출혈 직접 수용

상태: 직접 조작·청취 미수용. 자동 장착/Slate 입력 시험의 통과를 아래 체크로 옮기지 않는다.

프로젝트 루트의 PowerShell에서 실행한다. 준비된 세션은 개인 저장과 분리되어 있고 장비·재료·보상을 자동 제공하지 않는다.

```powershell
.\Tools\PlayInventoryAcceptance.ps1 -Session BleedAcceptance_Final_20261016 -Size 1920x1080
```

정상 종료 후 같은 명령으로 재실행한다. 패키지·해시는 `Saved/InventoryAcceptance/BleedAcceptance_Final_20261016/session.json`, 매 실행 명령·로그는 같은 폴더에 남는다. 다른 패키지를 쓰려면 새 세션 이름과 그 패키지의 `-PackageReport`를 지정한다. 기존 세션의 패키지를 바꾸지 않는다.

- [ ] 첫 전투·획득 전에 I 인벤토리의 캐릭터 탭에서 Bokusei를 확정한다. 장비 비교·장착, 검술 탭의 액티브 4슬롯에 원월참을 포함해 선택·적용한다. 장착 후 창을 닫고 이동·공격이 돌아오는지 확인한다.
- [ ] 자연 전투·드랍으로 출혈 장비를 획득하고, 보상 선택에서 출혈 전파·폭발/환급을 구성한다. 도달하지 못한 옵션은 **미도달**로 적는다. 자동 제공 시험의 장비 15004·보상 15003/15018과 구별한다.
- [ ] 준비 중 제작/강화 미리보기에서 취소 후 재선택·확정을 확인한다. 스킬 초안도 취소/적용하고, 화면의 네 슬롯과 실제 사용하는 스킬을 대조한다.
- [ ] 종료 전 장비·레벨·분배·재료·4슬롯을 촬영하고 정상 종료→같은 명령으로 재실행하여 대조한다. PCG는 새 던전/새 런이므로 보상 카드와 배치는 초기화되며 영구 장비·성장·슬롯은 남아야 한다. 카드 초기화를 저장 손실로 기록하지 않는다.
- [ ] 두 무리 연속 전투에서 기본 3타→원월참과 원월참 선사용을 각각 시도한다. 첫 처치, 회피를 눌렀을 때와 실제 회피했을 때, 다음 첫 타격, 진입 쿨다운, 다음 실제 원월참, 환급 횟수를 기록한다. 거리·접근 방향·치명타도 함께 적는다.
- [ ] 피격 직후 짧은 기본 입력과 유지 입력, 회피 후 공격, UI 열기/닫기를 확인한다. 피격 몽타주 대기와 만료된 입력을 구분한다. 입력·취소 규칙을 바꾸는 콘솔 명령은 사용하지 않는다.
- [ ] 군중 속 몸체·검 방향·주황색 적 예고를 계속 읽을 수 있는지 확인한다. 출혈/전파와 일반 적중이 구별되는지, 치명타와 다른 외형에서도 과도하게 가리지 않는지 확인한다. 타격음·출혈음 중첩과 회피/피격 반응을 직접 듣는다.

기록: 일시 / 해상도·품질 / 입력 장치 / 외형 / 자연 획득 또는 자동 제공 / 순서·접근 방향 / 기대와 실제 / 로그 시각 / 통과·실패·미도달.

자동 시험 영상은 무음·고정 시간 기록이다. 실시간 오프스크린 GPU CSV도 모니터 출력 지연·직접 조작·소리·장시간 성능을 보증하지 않는다. 현재 출혈 틱/전파와 일반 적중이 같은 효과 계열을 사용하므로, 크기가 작아졌다는 이유만으로 표현 구분을 수용하지 않는다.
