# 01. 프로젝트 설정·문서·실행 기준선

우선순위 P0 / 상태 구현 반영·잔여 검증 있음 / 선행 없음 / 규모 소

## 현재 근거와 문제

- `UPlayground.uproject`의 EngineAssociation은 `5.8`이며 두 Target은 `BuildSettingsVersion.V7`, `Unreal5_8`을 사용한다. `CLAUDE.md`, `PROJECT_OVERVIEW.md`는 5.4를 기재한다.
- 실제 AttributeSet 이름은 `UPGAtrributeSet`이다. 개요의 `UPGAttributeSet`과 다르며 `StageDevMap`과 스테이지/보상 코드도 개요에 충분히 반영되지 않았다.
- 설명 문서에는 복제 지원과 자동 데이터 검색 등이 적혀 있으나 현재 실행 품질은 별도 확인이 필요하다.

## 목표와 작업

1. 실제 사용 가능한 엔진 설치·툴체인·Content 확보 방법을 확인하고 Game/Editor 빌드 및 개발 맵 실행 방법을 기록한다. 문서에 맞추어 엔진을 낮추지 않는다.
2. 개요를 쿼터뷰 파밍 ARPG 목표, 현재 구현, 미구현/미검증 기능으로 나누어 갱신한다. 공통 원칙은 CLAUDE에만 유지한다.
3. StageDevMap을 포함한 맵별 용도와 GameMode/BP 설정을 에디터에서 확인한다. 작은 루프의 실행 진입점을 지정한다.
4. 한 번의 Editor 빌드와 Development 패키지 실행 결과, 오류 목록, 재현 절차를 기준선으로 남긴다.

## 범위와 주의

설정 변경 자체가 목표가 아니다. 엔진 업그레이드 재수행, 전체 클래스 이름 변경은 제외한다. 오탈자 타입을 바꿀 때는 별도 작업에서 BP/직렬화 참조와 리다이렉트를 검증한다. 멀티플레이와 출시 플랫폼은 요구 확인 전 완료 기능으로 표기하지 않는다.

## 수용 기준

- 신규 작업자가 문서만으로 동일 엔진과 시작 맵을 식별한다.
- Editor/패키지 실행 성공 또는 차단 원인이 로그와 함께 기록된다.
- 개요의 모듈·주요 타입·맵 목록이 실제 프로젝트와 일치한다.

검증 도구: 빌드 로그와 시작/종료 스모크 체크. 후속: 모든 작업의 공통 기준.

## 2026-09-19 구현 반영

UE 5.8.2 설치와 Win64 툴체인을 확인했다. Editor와 Game Development 빌드를 통과했다. 문서의 엔진 버전·AttributeSet 이름·개발 맵 설명을 정정했다. StageDevMap과 최종 Development 패키지의 NullRHI 25초 실행이 정상 종료됐다. 재현 명령과 기존 에셋 경고는 실행 보고서를 따른다.

상세 변경·재현 절차·최종 검증 결과: [1·2단계 실행 보고서](Stage12_Implementation_Report.md). 위 현재 근거는 최초 분석 시점 기록이다.
