# U9 직접 플레이 기록

상태: 미검증. 체크는 직접 확인한 항목만 표시한다. 정상 종료나 로그 오류 없음만으로 수용 통과를 판정하지 않는다.
실행한 패키지·해시·명령·로그는 같은 폴더의 JSON에 기록된다. 실행 시점의 소스 정보는 패키지 빌드 시점과 다를 수 있다.

## 시작과 재개

- 실행 도구: `Tools/PlayInventoryAcceptance.ps1`. 첫 실행은 새 세션을 만든다.
- 종료 후 출력된 이름을 `-Session <이름>`으로 전달하면 같은 저장/설정으로 재개한다.
- 다른 세션은 별도 저장이다. 개인 프로필을 복사하지 않는다. 치트·자동 처치·자동 회복 없이 HUD 안내로 전투를 시작한다.
- 프로세스 실행 중 같은 세션의 중복 실행은 거부한다. 실행기 자체가 강제 종료되어 `playing.lock`이 남으면 해당 게임 프로세스가 종료되었는지 확인한 뒤 그 파일만 제거한다.
- 패키지 변경 시 새 세션을 만든다. 기존 U9 세션은 U8 패키지/아레나를 유지한다. U10 이후 새 세션은 검증 보고서에 지정된 PCG 맵을 사용한다.
- PCG 던전은 현재 재실행 시 새 던전/새 런을 만든다. 캐릭터별 장비·레벨·분배·창고·재료·제작법·액티브 스킬 선택은 보존하지만, PCG 배치와 런 보상 카드·체크포인트 복원은 지원하지 않는다. 아레나의 같은 런 이어하기와 구분한다.

## 물리 입력·화면

- [ ] 실제 키보드 I 열기/닫기와 Esc 복귀, 클릭·스크롤·아이템 선택을 확인했다.
- [ ] 인벤토리 버튼 클릭이 뒤쪽 이동/공격으로 전달되지 않는다. 닫은 후 이동·공격·대시가 복구된다.
- [ ] 공격 버튼 유지 중 창 열기/닫기, Alt+Tab 후 복귀에서 공격 고착이 없다.
- [ ] 장착/해제·비교 대상·정렬·필터·즐겨찾기·잡동사니 표시가 실제 클릭대로 동작한다.
- [ ] 창을 연 상태에서 개발 콘솔 `r.SetRes 1280x720w` → `r.SetRes 1920x1080w`로 변경했다. 콘솔을 닫고 좌우 패널/축소 화면, 스크롤, 선택 및 제작 초안의 보존과 클릭 위치를 확인했다.
- [ ] 위 해상도 변경을 능력치 분배·분해·각인·담금질·명품화 미리보기에서 반복했다. 버튼/비용/확정값 잘림이 없다.
- [ ] 쿼터뷰/3D 액션에서 커서와 입력 복귀를 확인했다.

여기서 해상도 변경은 실행 중 출력 해상도 변경이다. GPU 부하에 따른 동적 내부 렌더 해상도(Dynamic Resolution) 검증은 별도다.

## 실제 파밍·성장·재개

- [ ] 직접 전투 → E/라벨로 획득 → 비교/장착 → 레벨 분배 → 다음 구간을 진행했다.
- [ ] 준비 단계에서 분해·제작의 비용과 변화량을 확인하고 취소/확정했다. 전투 중에는 제작할 수 없다.
- [ ] 아레나: 구간 완료 후 정상 종료하고 같은 세션으로 재개했다. 장비·재료·분배·진행을 전후 대조했다.
- [ ] PCG: 종료 후 재실행하면 현재 구현대로 새 런이 시작되는 것을 확인했다. 같은 런 복원으로 기록하지 않는다.
- [ ] 보스 완료 후 새 런에서도 같은 캐릭터의 장비·레벨·분배·재료·제작법·스킬 선택이 유지되고 보스 전리품은 창고로 이전된다. 런 보상 카드·진행 체크포인트만 초기화된다.
- [ ] 30분 이상 플레이에서 UI/드랍 누적, 입력 지연, 반복 사망·재시작 문제를 기록했다.

자연 드랍으로 만나지 못한 제작/등급은 '미도달'로 기록한다. 재료 지급 치트를 썼다면 별도 세션으로 구분하고 경제 수용에 포함하지 않는다.
